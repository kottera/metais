# Sources and their terms

Every text in this package is the METAIS project's own, written for it:
the manifest and its guide, the input schemas and meaning documents, the
templates, the stylesheet, the script, and the example's site
configuration and articles. No third-party text, code or image is copied
into it, and the example's articles are invented: the site, its author and
its address are fictional, and `example.org` is a domain reserved for
documentation by RFC 2606.

All of it is under the project's licence, the Apache License 2.0, as the
manifest's `license` says, with the repository's `NOTICE`.

The package follows two published formats, and copies neither's text:

- **The Atom Syndication Format**, RFC 4287 (IETF, December 2005),
  <https://www.rfc-editor.org/rfc/rfc4287>, which `feed.xml` is written
  in. The package uses the format's element names as any feed does; no
  text of the RFC is reproduced here.
- **HTML**, the WHATWG Living Standard, <https://html.spec.whatwg.org/>,
  which the pages are written in, by the same measure.

The body subset the articles' meaning document describes is this
package's own reading of a few Markdown block forms, written in its own
words; it quotes no Markdown specification.
