# notes

Keeps short notes in a plain-text file.

## Building

`notes` needs Go 1.24 or later.

```sh
go build ./cmd/notes
./notes
```

## Checking

`scripts/check.sh` vets and tests the module and checks its formatting.
Run it before every push.
