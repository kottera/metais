# ADR-006 — W6-9: the manifest keyword codes a vector produces

**2026-10-20, PLAN-2026-10-metais-v1 W6-9.** `man/keyword-codes` holds one
package for each of `manifest.const`, `manifest.contains`,
`manifest.dependent_required`, `manifest.forbidden`, `manifest.max_items`,
`manifest.min_length`, `manifest.one_of` and `manifest.unique_items`, and
each now names MTS-MAN-019 in the registry.

- **`manifest.any_of` and `manifest.one_of.ambiguous` cannot be produced by
  any 1.0 manifest.** The schema's one `anyOf` is beneath the name's `not`,
  so its failure is the `not`'s success. The `oneOf` branches of an output
  and of an entry are closed objects, each requiring its own source key,
  which the others do not allow, so no value matches two. A1 item 1
  registers both, because the schema uses `anyOf` and `oneOf`. They are
  listed for Wave 7 in `unwired.txt`, and are a finding for Ed: A1 item 1
  would need to register a code by whether its failure can occur, not by
  whether its keyword appears.
