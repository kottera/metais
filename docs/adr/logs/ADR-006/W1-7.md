# ADR-006 — W1-7: `input.coverage` and `output.coverage` (D6, D7 item 4)

**2026-10-23, PLAN-2026-10-metais-values-and-rules W1-7.** ADR-003
Amendment A2 ruling 7 gives D6's table a `coverage` row: `internal/finding`
registers `input.coverage` and `output.coverage`, each an error naming the
member of `values` no item holds as `missing`, its canonical JSON text, and
the manifest family registers neither, since the manifest schema never uses
the keyword (ADR-006 A1). The adapter gives one failure per missing member,
and the mapping locates each at the array. `schema.invalid` also reports a
`coverage` that breaks MTS-DAT-016's grammar, naming the keyword.

**D7 item 4.** `input.coverage` is a finding about the array as a whole
(A2 item 16): in an array validated in part it is suppressed and counted in
`input.validation.partial`'s `suppressed`, by the mapping's existing rule for
a finding at the array (`sup/coverage-partial`).
