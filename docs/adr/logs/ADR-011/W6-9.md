# ADR-011 — W6-9: hostile manifests without an open step, and the suite walked in parallel

**2026-10-20, PLAN-2026-10-metais-v1 W6-9.** Two of the wave orchestrator's
rulings, R-W6-9a and R-W6-9b, shape how this item's cases meet D16.

- **The YAML profile's cases cannot carry an `open` step (R-W6-9b).** An
  alias, billion laughs, a merge key, a custom tag, a second document and a
  duplicate key are refused with class `content` findings. `check` then
  runs the steps that do not need the manifest's model and adds the
  `report.step_skipped` that MTS-AUT-002 requires, and `pack` checks
  first. So these cases cannot give D16 item 3's "the same findings"
  through every opening command. Following W6-11's precedent
  (`docs/adr/logs/ADR-009/W6-11.md`), each of
  `man/hostile-billion-laughs`, `man/hostile-alias`,
  `man/hostile-merge-key`, `man/hostile-tag-python`,
  `man/hostile-tag-include`, `man/hostile-multi-document` and
  `man/hostile-duplicate-key` is tagged `security`. Each has a `validate`
  step expecting its exact findings, and a `check` step expecting the same
  findings and the `report.step_skipped`, both under lowered `bounds` and
  with nothing written. The runner admits no unexpected finding, and
  neither chapter 13 nor this ADR is amended. The tension between D16
  item 3 and MTS-AUT-002 is carried to Ed in the wave's closeout.
- **`internal/cli`'s walk of the suite is parallel (R-W6-9a).**
  `TestReadingRefusalsTriggered` ran inspect and the six reading commands
  over every vector package one at a time, in process. On a host shared
  with other Work Orders its package passed `go test`'s 10-minute bound
  in the gate's runs. Each package is now a parallel subtest, within the
  gate's `-parallel` share, with an `extract` destination of its own. The
  walk runs before `testenv.Home`, so no parallel subtest shares a
  `t.Setenv`. Every package still goes through inspect and every reading
  command, a refused package is still held to inspect's findings and the
  refused exit (D16 item 3), and the codes each command gave still feed
  the declared-refusal check after the walk. Removing the codes' feed made
  the test report every declared code as never triggered, and changing
  inspect's findings in the comparison made it report every refused
  package. The measured times are in PR #129.
