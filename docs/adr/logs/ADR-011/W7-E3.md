# ADR-011 — W7-E3: the §4.3 status widget and the §4.5 repository scaffold

**2026-10-20, PLAN-2026-10-metais-v1 W7-E3.** Two example packages are
under `examples/`, and Wave 6's harness, `TestExamplePackages`, runs over
each: check and test green, packed and green again, and previewed with
`--optional all` and `none` into output that validates (SC4).

- **`examples/status-widget`, PRD §4.3.** One manifest, one schema, one
  template: it renders `status.html`, one HTML fragment escaped as `html`,
  from one JSON object. Its two examples are a degraded service with
  components and text that must be escaped, and an operational service
  given only what is required. SC3's test, `TestSC3StatusWidget` in
  `cmd/metais/sc3_test.go`, builds the binary and runs it as a scheduled
  workflow would: the JSON written to a data directory, one
  `metais validate`, one `metais render`, and no other command or flag. It
  was seen red first, refused with `package.not_found` before the package
  existed.
- **`examples/repo-scaffold`, PRD §4.5.** It renders a Go repository from
  one project description: the command, its package and the package's
  test, `go.mod`, a README, `.gitignore`, `.editorconfig` and
  `scripts/check.sh`. The command's directory, the package's directory and
  file names, and each extra command's directory are path templates over
  the inputs, the extra commands through `for_each`. `scripts/check.sh` is
  `executable: true`. The CI workflow and the container files are written
  only when `ci` or `container` is true. The templates tree holds
  `.github/workflows/`, and the mirror of `templates/` renders the
  dot-files beside the plain ones. Each example's rendered repository
  passes its own `scripts/check.sh`: `go vet`, `go test` and `gofmt`.

Both packages are written in this project's own words, and each records
that in `references/sources.md`. The scaffold writes no licence text: it
names a licence by its SPDX identifier and tells the author to add the
text.

Every Go file the scaffold renders begins with a copyright line from the
project's `owner` and `year` and an `SPDX-License-Identifier` line from
its `license`, all three required. Its examples are this project's own
and name Kottera, 2026 and Apache-2.0, so their expected Go files begin
with the header AGENTS.md requires of every Go file in the repository,
and `TestLicenceHeaders`, which walks every Go file, nested modules
included, holds them as it holds the rest. It was red over the expected
files before the header was rendered. The expected trees each hold a
`go.mod`, so `go list ./...` and the host-facts walk leave them out as
nested modules.

Each package carries the `.gitattributes` that `metais init` writes,
`* -text`, so a checkout never rewrites the line endings its examples'
expected outputs are compared by. It is a top-level dot-file, which a
source directory ignores.

The generator chooses an array item's string from the schema's `examples`
by the item's position, so an item schema with one example per property
makes every item of the array the same. The scaffold's extra commands
declare `uniqueItems` and three examples for each field, so a preview
holds three distinct commands.
