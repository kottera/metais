# ADR-011 — W6-3: the runner fails a crash, compares exit statuses, and carries the SC7 harness

**2026-10-20, PLAN-2026-10-metais-v1 W6-3.** The runner has two checks of
its own:

- **`crash`** fails a step whose process exits through a Go panic or a
  runtime fatal error. It reads the Go runtime's traceback from standard
  error, so it sees a crash behind a driver too. The reference driver
  forwards a crashed tool's whole standard error.
- **`host-fact`** is ADR-009 D16 item 1's check 2. It runs where a runner
  is given the host's facts: in the SC7 harness and in the self-proof.

D12 item 4's comparison of A and B now covers every process's exit status
as well as its bytes, as ADR-009 D16 item 1's check 3 asks. The self-proof
has a fault for each new check: `panic`, `fatal` and `host-path`.

The SC7 harness is a mode of the runner (`sc7`), which `TestHostIsolation`
turns on. `TestConformance` runs D12's environments as they were.
Measured on the compiled test binary, alone and not race-built, as
`go test -c ./internal/conformance` then
`/usr/bin/time -p conf.test -test.run '^TestConformance$'`: with go1.26.9
on a shared 16-core darwin/arm64 host, over the 397 vectors and 519 cases
in the tree at the time, it took 29.3 s of wall time and 111.5 s of CPU
time.
