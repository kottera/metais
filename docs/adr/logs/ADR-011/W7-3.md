# ADR-011 — W7-3: the worked package of appendix B, and the gen/ area

**2026-10-20, PLAN-2026-10-metais-v1 W7-3.** `spec/B-worked-package.md`
builds one package, `release-notes`, on the authoring golden path: a
manifest, one input with its schema and meaning document, two templates
and one example, checked, tested and packed. Every file it shows is an
example block (D4 items 1 and 2) of one of three vectors under
`spec/conformance/vectors/gen/`:

- `gen/worked-package`, the finished package, which check, test and pack
  accept, and whose packed file opens;
- `gen/worked-package-check`, a first draft whose template reads a field
  the schema does not declare, which check and pack refuse;
- `gen/worked-package-test`, a second draft whose hand-written expected
  file differs from the render, which check accepts and test and pack
  refuse.

A vector's area is its first statement's, so the `gen/` area needed a
statement of chapter 1. MTS-GEN-001 states as a requirement what §1.5
already said: a conforming authoring tool's check reports no error for a
conforming package, and a package it reports one for does not conform.
Each vector cites it first, and then the statements of the chapters it
illustrates. `TestExamplesMatchVectors` checks the appendix, and was seen
red against a shown template that differed from its vector's file by one
word. `docs/dev/rounds/sc9.md` is the runbook for SC9's round, which
starts from the appendix.
