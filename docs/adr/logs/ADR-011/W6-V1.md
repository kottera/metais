# ADR-011 — W6-V1: merge-check.sh's planted statements never collide

**2026-10-20, PLAN-2026-10-metais-v1 W6-V1.** A5's `merge-check.sh` planted
MTS-AUT-043 and MTS-AUT-044 as new statements. W6-1 made both real `pack`
statements, so on `main` at `f995ae5` the statements case failed: the side
the driver kept already held the other side's number, and
`TestStatementsWellFormed` reported both as used twice. The collision case
passed only because its planted 043 collided with the real one. The drivers
resolved every case correctly.

The planted statements now take the two numbers after the highest
`MTS-AUT` number anywhere in the clone's `HEAD`. Section 1.4 assigns an
area's numbers in order of addition and never reuses one, so no statement
`HEAD` holds can have either, however chapter 13 grows. Every case proves
what it proved: the drivers keep one side, regeneration restores the
other, and a real duplicate fails `TestStatementsWellFormed`.
