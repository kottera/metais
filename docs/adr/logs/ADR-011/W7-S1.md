# ADR-011 — W7-S1: the metais.org site, with the schemas at their `$id`s

**2026-10-20, PLAN-2026-10-metais-v1 W7-S1.** D7 makes `spec/schemas/`
mirror `https://metais.org/schemas/`, and ADR-001 A1's `README.md` sends
every package's reader to `https://metais.org/`. This item adds the site
that serves both, published by GitHub Pages from a release tag:

- `site/public/`: the home, install and getting-started pages, and
  `CNAME`;
- `site/build.sh`, which writes the published tree with every file of
  `spec/schemas/<path>` at `schemas/<path>`, copied from the commit being
  built rather than committed twice;
- `site/site_test.go`, which holds D7's mapping: each schema's `$id` names
  the path the build publishes it at, byte-identical, and nothing else is
  published under `schemas/`. It also holds every `metais` command line on
  the pages to the commands and flags of `metais help`;
- `.github/workflows/pages.yml`, gated on the repository being public, so
  it is inert until the release; `docs/dev/release.md` carries the go-live
  steps.
