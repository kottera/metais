# ADR-011 — W2-1: the specification's revisions as the site's input (A8 items 1 and 2)

**2026-10-23, PLAN-2026-10-metais-public W2-1.** The site's build step
exports the specification's text for the pages A8 items 1 and 2 serve:
the checkout's own `spec/` as the draft, at `/spec/draft/`, and the files
of every `spec-<M>.<m>` tag as that revision, at `/spec/<M>.<m>/`, in
numeric order. Each Markdown file of `spec/` is an HTML fragment, with its
title and headings, and its page's path is the revision's path for
`README.md` and the file's name without `.md` below it for every other
file. A link to another file of the revision becomes a link to its page.
Any other relative link becomes a link to the file in the repository, at
the commit for the draft and at the tag for a release. No `spec-*` tag
exists yet, so the tag path is tested against a fixture repository with
three. The pages themselves are W2-2's.
