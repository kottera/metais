**Rulings recorded in the plan.**

- **D11 item 9's 60 seconds binds the default conformance run,
  `TestConformance`** (plan §10). It does not bind the whole package with
  the tests that re-run the suite. W5-NB3 brought `TestConformance` back
  within it, as recorded above.
- **D3 item 3 permits gaps in statement numbers** (plan §11b). Plan §2's
  statement-number blocks therefore need no change to this ADR. A number
  allotted in a block and never used is never assigned. Within an item,
  numbers are still taken in order of addition, and no contiguity check
  is added.
- **Wave 4's blocking fix W4-V1**
  ([#77](https://github.com/kottera/metais/pull/77)) committed a fixture
  that `.gitignore` had dropped. It added `!/spec/conformance/**`, so that
  no conformance fixture can be dropped again.
