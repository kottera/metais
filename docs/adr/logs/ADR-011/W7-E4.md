# ADR-011 — W7-E4: the §4.4 example package, the static site

**2026-10-20, PLAN-2026-10-metais-v1 W7-E4.** `examples/static-site/` is
PRD §4.4's package, a source directory beside the other examples (plan
§13), not a conformance vector. It renders one HTML page per article from
a Markdown collection with frontmatter (`for_each: inputs.articles`, named
by `sources.articles[fan_out.index0].stem`, a draft dropped by `when`), an
index page and an Atom feed over the same collection and the same site
configuration, and copies its stylesheet and script from `assets/`, which
the pages link to through the `asset` tag. `TestExamplePackages` runs over
it: check and test green, it packs, and it previews with `--optional all`
and `none` into output that validates.

The 1.0 dialect has no filter that turns Markdown into HTML (chapter 8
§8.1.10), so the package writes the article body's blocks itself — section
headings, bulleted lists, code and paragraphs, each text escaped — and its
articles' meaning document states that subset as what the body means. Its
`references/sources.md` records that every text in it is the project's
own, under Apache-2.0, and that it follows RFC 4287 and HTML without
copying either's text.
