# ADR-008 — W5b-5: help refusals by family, and the JSON help goldens pretty-printed

**2026-10-19, PLAN-2026-10-metais-v1 W5b-5.** A1 landed. A refusal a loop
over the finding registry declares carries a gist, its cause without the
code's own words, which `familyRefusal` in `internal/cli/decl.go` sets
beside the cause; `renderRefusals`, `sampleRefusals`, `packageRefusals`,
`checkRefusals` and `testRefusals` build their registry refusals through
it, or set the gist themselves where check's cause names a severity. The
causes and next steps of every refusal are unchanged, so `help --json`
gives each code's declaration as before, and only help's own declaration
(its second operand, an example, and its `usage.unknown_topic` cause)
and the new topic moved in `help.json`. A check code whose family check's
subjects name no subject for, `output.declaration.validate_kind`, has no
gist and is listed on its own.

`commandText` lists the refusals without a gist as before, then one line
per family (`families`, `family.pattern`); `refusalsByNext` writes the
`refusals` topic, with no command and for each command. The help goldens
gained `topic-refusals.txt` and one `topic-refusals-<command>.txt` per
command. `metais render --help` went from 1,138 lines to 305, and
`metais check --help` from 584 to 120.

`help.json` and `command-help.json` are held indented by two spaces, as
`json.Indent` writes them, so git merges them line by line. `TestHelpGolden`
compacts a JSON golden and compares it with what the tool prints, byte for
byte, fails a JSON golden that is not in the form `-update` writes, and
asserts that the tool's output survives the round trip through that form
exactly, so a one-byte change in what the tool prints still fails. The
tool's own `--json` output is unchanged.
