# ADR-008 — W2-1, examples first in a command's help, and `--out` for every command that writes (Amendments A3 and A4)

**2026-10-22, PLAN-2026-10-metais-ux Wave 2.** Amendments A3 and A4 are
implemented.

- **A3.** `commandText` prints a command's examples straight after its
  usage lines, before the detail, operands, flags, prints and refusals.
  `render`'s examples lead with a render from a data directory, a preview
  from sample data, and one output written to a file with
  `--out - --only <path>`. `extract`'s lead with its references, and
  `sample`'s with a packed package. `TestHelpExamplesFirst` holds every
  command to the order, by both routes. It was red for every command, 38
  help texts, before `commandText` changed. The help test's command-line
  parse check accepts an example that ends in a redirection of standard
  output to a file.
- **A4.** `unpack`, `extract` and `sample` declare `--out` where they
  declared `--to`, and every cause, next step, synopsis and example
  follows. `TestDirectoryFlagAgrees` gives each of the five commands that
  write `--out` with `--dry-run`. It was red with `usage.unknown_flag`
  before the declarations changed. The text that named the flag changed
  with it:
  - ADR-005's, ADR-007's, ADR-011's and ADR-012's text above their logs;
  - `docs/cli/sample.md`, `internal/skill/SKILL.md` and the site's getting
    started page;
  - the conformance adapter's and the guarantees' command lines.

  Implementation logs keep the spelling of their day.
- **The UX scorer** reads unpack's and sample's directory from `--out`,
  and from `--to`, which the baseline's recordings hold. That is the
  ruling on the scorer's flag reading. `TestDirectoryFlagSpellings` is
  red for `--out` without it.
- The help goldens and `help.json` were regenerated by `regenerate.sh`.
