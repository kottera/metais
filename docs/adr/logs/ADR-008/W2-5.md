# ADR-008 — W2-5: inspect and the help send a supplier to `render --sample` and `sample` (Amendment A8)

**2026-10-22, PLAN-2026-10-metais-ux W2-5.** Amendment A8 is implemented.
`internal/cli`'s `inspectNext` lists the real document's path, then
`render --sample` and `sample`, then the first example, then `unpack` for a
packed package or `check` for a source directory. The constant `exampleIs`
carries item 3's sentence, which `inspect`'s Examples section, its example
step, its help and `sample`'s help print. `render`'s and `sample`'s help
name the supplier they serve, and `sample`'s group is "Supplying and
rendering". `internal/skill/SKILL.md`'s fictional-data rule and section
name `render --sample` and `sample`, and its consuming steps no longer list
or read an example's files.

- `supplier_test.go` holds the amendment: `TestInspectNextOnTheFly`,
  `TestInspectExamplesSay`, `TestSupplierHelp` and
  `TestSkillSendsNoSupplierToAnExample`. Each was red before the change.
- The help goldens and `skill-print.md` were rewritten by `-update`.
- ADR-007 A2, allotted to this item, is unused: the generator,
  `render --sample` and `sample` behave as ADR-007 decides, and only their
  help and `inspect`'s listing change.
