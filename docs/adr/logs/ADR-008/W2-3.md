# ADR-008 — W2-3, `metais help templates` and `metais help manifest` (Amendment A6)

**2026-10-22, PLAN-2026-10-metais-ux Wave 2.** Amendment A6 is
implemented.

- **The topics.** `templates` and `manifest` join the topic table in
  `internal/cli/help.go`, after `inputs`, so the overview, `help --json`
  and the help goldens carry them with no change to either document's
  shape; `metais.help/1`'s schema is unchanged. Each topic's body is its
  own file, `help_templates.go` and `help_manifest.go`, printed from a
  table: one row per filter, with its line, its example and what it gives,
  and one row per manifest field path, with its text and example.
- **The drift tests.**
  - `TestTemplatesTopicFilters` holds the filter table to
    `template.Dialect().FilterNames()`, the 68 filters the dialect
    registers today. It is pinned false in the test itself: a catalog with
    an invented filter, a row naming no filter and a repeated row are each
    reported. It was also seen red for real, with a dummy filter added to
    `internal/template/filters`'s catalog in a copy of the tree:
    `undocumented: zz_dummy` and `metais help templates lists no filter
    zz_dummy`.
  - `TestTemplatesTopicExamples` renders every example of the page over
    the inputs the page states, the escaping examples with HTML escaping,
    and requires what the page says each gives.
  - `TestManifestTopicFields` holds the field table to the field paths of
    the embedded manifest schema, walked from its root through `$ref`,
    `oneOf` and `items`; an entry's field is covered by the `outputs[]`
    row of the same key unless it has a row of its own. It is pinned false
    in the test with invented fields at the root, in an input and in a
    template entry. It was also seen red for real with a field added to
    `$defs/input` in `spec/schemas/1.0/manifest.schema.json` and its
    `internal/specdata` copy: `no row for the schema's inputs[].zz_probe`.
  - `TestManifestTopicExample` builds the page's example manifests with
    `manifest.Build`, the builder `check` uses.
- **Reachability.** `help`'s operand names every topic from the table;
  its examples are `metais help`, `metais help templates`,
  `metais help manifest`, `metais help refusals render` and
  `metais help --json`. `internal/skill/SKILL.md` names both topics in its
  steps for writing a package and in "When stuck".
  `TestAuthoringTopicsReachable` was red with `main`'s declaration and
  skill, six failures, and is green with them changed.
- **What the topics leave out**, where the specification adopts Shopify's
  standard filters by reference and does not restate them: `first` and
  `last` on a string, and `round`'s tie-breaking beyond the example. The
  less common tags (`tablerow`, `cycle`, `increment`, `ifchanged`,
  `liquid`) are not described; chapter 7 is named for them.
- The help goldens were regenerated by `regenerate.sh`.
