# ADR-008 — W6-1: metais pack

**2026-10-20, PLAN-2026-10-metais-v1 W6-1.** D9's `pack` is declared, and
with it the authoring golden path shows in help (D15 item 2). Its result,
`metais.pack/1`, is `file`, `size` and `digest` as item 4 lists them, with
`entries` (ADR-007 D7 item 6's entry count) and `dry_run`, as unpack's
result carries it; `file` is absent when the caller named the file (D11
item 5). `--out -` joins render's in D11 items 1 and 2: standard output
carries the package and nothing else, and the document or the human summary
goes to standard error. `usage.archive_to_terminal` and
`usage.not_a_source_directory` now word their messages for any command
that writes an archive or needs a source directory, since pack gives both.
`pack` declares `--fail-on` (R2-134), and every code check and test declare,
each pointing at the step that reports it.
