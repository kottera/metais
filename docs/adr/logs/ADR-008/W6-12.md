# ADR-008 — W6-12: grep's --max-results default under a lowered grep-matches

**2026-10-20, PLAN-2026-10-metais-v1 W6-12.** D5's `grep` item 5 gives
`--max-results` a default of 100 and a range of 1 to the `grep-matches`
limit in force. Under a `grep-matches` lowered below 100, the default lay
outside that range and was used anyway, so `grep` reported more matching
lines than the limit. The default is now the lesser of 100 and the limit,
and a search past it is cut there and marked as truncated (ADR-009 D2
item 6). `internal/cli`'s `TestHostileGrepMatches` holds it.
