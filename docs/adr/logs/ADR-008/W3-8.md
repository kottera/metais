# ADR-008 — W3-8: generated data is offered only to a person who asked for it, and a preview is a render (Amendment A10)

**2026-10-22, PLAN-2026-10-metais-ux W3-8.** Amendment A10 is implemented.
`internal/cli`'s `inspectNext` no longer lists the first example: after the
real document's path come `render --sample` and `sample`, each beginning
"Only for a person who asked for …" and ending with the constant
`generatedNever`, then the route to editing the package. The constant
`generatedServes` names the person `render`'s and `sample`'s help serve,
and both help texts and `inspect`'s end their account of generated data
with `generatedNever`. `exampleIs` now says an example is not a preview,
which is a render from generated data. `internal/skill/SKILL.md`'s
fictional-data rule counts "show me what it produces", runs
`metais inspect <package>` first and never shows an example's expected
outputs; its section "Fictional data or a preview, when asked for" is
`inspect`, then `render --sample`, whose render is the preview, or
`sample`.

- `supplier_test.go` holds the amendment: `TestInspectNextOnTheFly` and
  `TestInspectExamplesSay`, amended, the new `TestInspectPreviewIsARender`,
  and `TestSupplierHelp` and `TestSkillSendsNoSupplierToAnExample`,
  amended. Each was red against the code before the change.
- `TestInspectExamplesInNameOrder` no longer checks the example step,
  which is gone; the order of `result.examples`, which it still checks,
  is what the step was taken from.
- The help goldens and `skill-print.md` were rewritten by `-update`. No
  chapter of the specification, published schema or vector changes: none
  describes the help or `inspect`'s next steps.
