# ADR-008 — W2-2: the overview and the no-command line send a package to `inspect` and `read` (Amendment A5)

**2026-10-22, PLAN-2026-10-metais-ux W2-2.** Amendment A5 is implemented.
`internal/cli`'s overview prints the paragraph `readInPlace` between the
description and the usage line, so `metais`, `metais --help` and
`metais help` each say, before anything else they list, that a package is
read in place with `inspect`, `read`, `ls` and `grep` and is not unzipped.
`usage.missing_command`'s hint in `internal/finding`'s registry says it on
the line under the refusal. The consuming path in `decl.go`'s `paths` gains
`render --sample` and `sample`, and requires `sample`.

- `TestFirstSightReadsInPlace` holds the three outputs' text before the
  usage line, and the hint line; `TestConsumingPathOnTheFly` holds the
  path's on-the-fly routes and its having no route through a shipped
  example. Both were red before the change.
- The help goldens and the registry's generated copies were rewritten by
  `regenerate.sh`.
- `internal/skill/SKILL.md` already tells an agent never to unzip a
  package, and names no route this amendment changes.
