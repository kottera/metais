# ADR-008 — 2026-10-23-fields-cut-names-whole-schema, a field listing's cut names the command that prints the value whole (Amendment A16)

**2026-10-23, outside a train (metais-ux), before v1.0 as Ed Funnekotter
ruled.** Amendment A16 is implemented.

- **The marks.** `internal/schema`'s listing ends a cut value
  `[…+N bytes; metais schema <package> <input> prints it whole]` and cut
  constraints `[…; metais schema <package> <input> prints every
  constraint]`, naming `metais schema <package>` in the combined listing.
  The bounds, 1024 and 4096 bytes, are unchanged. `metais schema -h`
  states the rule, that it is by bytes and not by values, and the marks;
  `metais.schema/1`'s `constraints` description says the same.
- **The proofs.** `TestSchemaFieldsLongEnum` lists the DORA report's
  root causes, an enum longer than 1024 bytes: the line either shows
  every value or names the command, and that command prints every value.
  It was red with the earlier `[…+N bytes]` mark. `TestFieldsCuts` holds
  each mark's text, for a constraint, a title, a condition and the
  constraints' cut.
- **Generated files.** The help goldens of `schema` were regenerated by
  `regenerate.sh`.
