# ADR-008 — W6-4: the pseudo-terminal proof of D16 item 6

**2026-10-20, PLAN-2026-10-metais-v1 W6-4.** D16 item 6 landed as
`internal/hostfs`'s `TestPresentationUnderTerminal`, an external test of
the package. It is hostfs's because it opens its pseudo-terminal through
`golang.org/x/sys`, which only hostfs may import, its tests included
(ADR-010 Amendment A1 item 4, `TestLayers`); being external, it may import
`internal/cli`. It builds the tool and
runs each of five lines twice: under a pseudo-terminal, on standard input,
output and error, with `NO_COLOR` and `TERM` set to sentinels; and piped,
with neither set. The lines are a render that writes two containers, `test`
and `inspect` with their findings and messages, a document under
`--color always`, and a refusal. The two runs must give the same status,
the same bytes on both streams and the same files, and no sentinel may
appear in any of them. The terminal is raw, so it hands on the bytes the
tool wrote.

The control is `fault.ColourJSON` (bit 10), whose seam in `internal/cli`
colours a JSON document written to a terminal, whatever `NO_COLOR` and
`--color` say. Faults never reach the built tool, so the control runs the
test binary itself as the tool: `TestMain`, given its arguments in the
environment, runs `hostenv.Isolate` and `cli.Run` as `main` does, with the
fault set it names. It must pass without the fault and be caught with it.
`TestPresentationNeverReachesJSON` carries the same control in-process,
with the terminal faked, so the fault's seam is pinned in every
`go test`.

The test opens its pseudo-terminal itself, in test-only code over
`golang.org/x/sys/unix`, through `/dev/ptmx`. On linux it unlocks the
slave with `TIOCSPTLCK` and names it by `TIOCGPTN`. On darwin it grants
and unlocks it with `TIOCPTYGRANT` and `TIOCPTYUNLK`, and names it
`/dev/ttys` and the master's minor device number in three digits, as
`ptsname` does. That avoids `TIOCPTYGNAME`, whose buffer needs `unsafe`,
which the directive rule refuses in every file. The terminal's output
processing is turned off through termios, without `golang.org/x/term`,
which only `internal/hostenv` may import. Its one skip is the probe
`requirePTY`. The probe skips
the test on a host where no pseudo-terminal opens, and names why: another
operating system, or a device the host refuses. W6-4's own host, a
sandboxed darwin/arm64 runner, opens `/dev/ptmx`, grants and unlocks it,
and is refused its slave device, so the test skipped there. The slave's
name matched what `TIOCPTYGNAME` gives on that host. Plan §6's matrix act runs it on darwin
and linux.
