# ADR-004 — W1-5: Amendment A2's `duration` filter

**2026-10-23, PLAN-2026-10-metais-values-and-rules W1-5.** Decision item 4
and rulings 9, 10 and 12 are built. `duration` lives in
`internal/template/filters` beside `slug`, registered by `All()`, so a
template and a manifest expression know it alike (D16 item 5). Chapter 8
§8.1.13 (MTS-FLT-021, MTS-FLT-022) and Appendix A's ISO 8601 hunk landed as
`b0cbb230` wrote them. `template.duration_input` and
`template.duration_format` were registered as `b0cbb230` wrote them, and
regenerated.

- **What it reads.** Whole seconds, from 0 to 2⁵³ − 1. An ISO 8601
  duration by chapter 8's ABNF. With `fields:`, a string of that many
  fields separated by `:`. nil gives nil. A number written as an integer
  beyond 2⁵³ − 1 is a float to the template (D4 item 2), so it is refused
  with the reason `kind`, as a float is. `range` comes from an integer
  below zero, an ISO duration or a field string longer than 2⁵³ − 1
  seconds, and a field beyond its unit. `calendar` names a string beginning
  `P` that holds `Y`, or `M` before any `T`, with or without `fields:`. Any
  other string is `form`.
- **The format** compiles when the template is parsed, as `date`'s does. A
  literal format outside the set is `template.duration_format` in a
  template and, through `internal/loader`, in a manifest expression.
  `internal/cli`'s codes for a manifest expression gain the code, as the
  amendment's Implementation paragraph says. The largest unit the format
  names takes the whole count, and what lies below the smallest unit named
  is dropped.
- **Charges** (decision item 7). The result is charged as built, as
  `date`'s is, and nil by its shallow size. `tpl/charge-duration` renders at
  43 units and at 39 for nil, and is refused one unit below each.
- **Shared sentences.** W1-4 had not merged, so this item landed whole:
  MTS-MAN-018's hunk, MTS-TPL-063's row and chapter 8's `8.1.14` heading.
  MTS-FLT-014's wording is Wave 2's. `number` and `amount` stay
  `template.unknown_filter` until W1-4 builds them.
- **Vectors:** `flt/duration`, `flt/duration-fields`,
  `flt/duration-refusals` (every reason), `flt/duration-format` (at parse,
  at render and in a manifest) and `tpl/charge-duration`.
