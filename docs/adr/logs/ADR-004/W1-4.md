# ADR-004 — W1-4: `number` and `amount`, with Appendix C's currency table

**2026-10-23, PLAN-2026-10-metais-values-and-rules W1-4.** Amendment A2's
decision items 1 to 3 and 7 are implemented, by rulings 2 to 8 and 12.
`internal/template/filters` holds `number` and `amount` beside `slug`,
registered by `All()`, so a template and a manifest expression apply them
alike (D16 item 5).

- **One reading of a number.** A number's value is
  `strconv.FormatFloat(f, 'g', -1, 64)` read into a `big.Rat`, rounded by
  `Rat.FloatString`, whose last digit rounds half away from zero, as
  `round` rounds; `FormatFloat(f, 'f', n, 64)` is never used, and
  `TestNumberNotFormatFloat` names the values where the two part. A decimal
  text is rounded on its own digits, in time linear in its length, which
  the input's shallow size has charged; `TestTextDigitsMatchNumberDigits`
  holds the two readings to one value, and `TestNumberAgreesWithRound`
  holds `number` to `round` (ruling 7).
- **Appendix C is a Go table**, `minorUnits`, held equal to
  `spec/C-currency-minor-units.md` by `TestCurrencyTable`, which parses the
  appendix; it is not generated at build time.
- **The codes.** `template.number_input` and `template.amount_currency`
  are registered as `b0cbb230` wrote them. A literal code is judged at
  parse in a template and in a manifest expression: `ParseCodes` and the
  loader's manifest-expression codes gain `template.amount_currency`, and
  every command that opens a package declares it. The finding never holds
  the code (`TestAmountCurrencyHoldsNoCode`).
- **The charges** (decision item 7): the shallow sizes of the input and of
  every argument, then the result's length, or nil's shallow size.

Chapter 8 §8.1.10 to §8.1.12, Appendix C, Appendix A's `[ISO 4217]`, the
README's line for it, and the shared sentences of plan §3 (chapter 3's
MTS-MAN-018, chapter 7's MTS-TPL-063 row and chapter 8's `8.1.14` heading)
land from `b0cbb230`. Until W1-5 merges, `duration` stays an unknown
filter. The vectors are `flt/number`, `flt/number-rounding`,
`flt/number-strings`, `flt/number-refusals`, `flt/amount`,
`flt/amount-currency` and `tpl/charge-number`.
