# ADR-010 — W7-4: the log completed from the plan's wave verdicts — Wave 1's module, data model and version, and the release builder carried

**2026-10-20, PLAN-2026-10-metais-v1 W7-4.** Plan §7 to §12 name ADR-010
in every wave. This log recorded Waves 2 to 6, and of Wave 1 only W1-4's
tripwires. It did not record W1-1, W1-5 or W1-7, the Wave 2 items for D6,
D7 and D14 item 5, or the fact that D12's release builder was not built
in Wave 6. This entry records them from the plan's verdicts and the

([wave 1](../../../briefs/brief-plan-2026-10-metais-v1-wave1.md),

**Wave 1.**

- **D1, D2 and D15 item 3:** W1-1
  ([#8](https://github.com/kottera/metais/pull/8)) landed:
  - `go.mod`, D1 item 1's three lines;
  - `cmd/metais/main.go`, D2's one line;
  - `internal/cli`'s empty shell, and `internal/hostenv`;
  - `internal/fault`'s `Set` (D13 item 2, with no fault yet);
  - `internal/testenv`, `internal/specdata`'s copier and the
    licence-header check;
  - AGENTS.md's extended gate: the static build, the six-target vet and
    build, and the specdata drift.

  The empty shell exited 2 on every invocation until Wave 2's command
  table replaced it.
- **D5 item 4, the data model:** W1-5
  ([#10](https://github.com/kottera/metais/pull/10)) landed a sealed
  six-kind `Value` in `internal/liquid/value`. A number keeps its literal,
  and an object keeps unique names in UTF-16 code-unit order. Plan §7 ruled
  that it lives there, using the standard library only, and that Wave 2's
  adapter converts it to the schema library's form.
- **D12 item 3, the version:** W1-7
  ([#9](https://github.com/kottera/metais/pull/9)) landed
  `version.String()`, `Implements()` and the test-only `Override`.

Not every Wave 1 gate ran on the pinned toolchain: W1-4's gate and the
verifier's ran on go1.26.2 under `GOTOOLCHAIN=local`. Wave 1 also proposed
Amendment A1 ([#16](https://github.com/kottera/metais/pull/16)), and Ed
ruled Amendment A2 ([#23](https://github.com/kottera/metais/pull/23)).

**Wave 6: D12's release builder was not built.** Plan §12's acceptance
says the release builder refuses each of its refusals, and produces
matching `SHA256SUMS` on two runs. That acceptance is not met. The
builder, `internal/tools/release`, needs a way past ADR-009 D16 item 3's
symbol rule, which refuses `go build`, git, the environment and file
writes in non-test module code. Ed's design session
`01a1566e-2786-7173-84ff-c1485fcf8cdf` decides that. The plan
orchestrator moved the builder to Wave 7, to be built once Ed has ruled
(plan §12 and §13).
