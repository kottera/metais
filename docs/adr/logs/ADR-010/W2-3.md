# ADR-010 — W2-3: sinks, the dry run as a wrapper, and test's comparison as a sink

**2026-10-21, PLAN-2026-10-metais-render-seams W2-3**, Amendment A7 items
2, 7, 9 and 10. ADR-005 D13's phases 3 and 5 left `internal/render` for
`internal/render/sink`, behind the `Sink` interface of item 7, and
`internal/render` reaches `internal/hostfs` only through `CheckPaths`.

- **Item 7.** `sink.Sink` is `Check`, `Status`, `Emit` and `Close`.
  `render.Run` takes a `render.Sink`, the two of its methods the entry
  point calls, and hands `Check` the paths of the top-level files in
  planning order, so findings are made in the order they were. Each sink
  is a file of its own: `newdir.go` (D14 item 1, `hostfs.StageNew`),
  `existing.go` (D14 item 2 as ADR-005 A1 amends it, `hostfs.Existing`),
  `archive.go` (D17), `content.go` (D18 item 1) and `compare.go`, `test`'s
  comparison of an example's render with its expected tree in memory
  (ADR-007 D5). Which of the two directory sinks `--out` is depends on
  whether the directory exists, which phase 3 finds out, so
  `directory.go`'s `Directory` makes phase 3's first step, opening out's
  nearest ancestor, and is then the sink it found. `dryrun.go`'s `DryRun`
  wraps any sink, running its `Check` and `Status` and never its `Emit`
  (D16 item 1). `Emission` is `render.Emission`, since `Run` reads it:
  either it ended, with its finding when it failed, or it is a write to
  standard output that `internal/cli` runs after the report as
  `outcome.stream`.
- **The command constructs the sink.** `internal/cli/render.go` chooses
  one file's bytes, the archive or the directory from the line, and wraps
  it under `--dry-run`; `streamsBytes` is unchanged and still decides
  standard output before the command runs. `test` gives each example a
  `sink.Compare`; the comparison, its codes, its diff caps and the
  unified diff (`diff.go`, which was `internal/cli/difftext.go`) moved
  with it, and `test` copies what it found into its result record, whose
  shape is the command's.
- **Item 10.** The confinement detector with `SkipConfine`'s control and
  `TestExistingDestinationDetector` with `ReadExisting` and
  `RemoveForeign` run through the command, unchanged, and pass. The
  sinks write only through `hostfs`'s write shapes.

The relocation of `emit.go` and `destination.go` is its own commit,
before the interface's. Of the tests that moved: `TestPathRefusal` is in
the sink package's `findings_test.go`; `TestAssetBytesStreamed` and
`TestRenderCommitAbortsAFailedWrite` are in `newdir_test.go`, through
`render.Run` to the directory sink, the second planning its path through
a file with `SkipConfine` as the render's seam, since a sink's test
cannot build a `render.File` by hand; and `TestEditScript` is in
`diff_test.go`. `TestTestDiffCaps` names the caps by their new package.
