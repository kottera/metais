# ADR-010 — W1-4b: CI's third tier fits a 2-core runner by splitting internal/conformance by -run (A8 item 4)

**2026-10-22, PLAN-2026-10-metais-public W1-4b.** Written at the train's
close, 2026-10-26, by W4-3: the item wrote no entry, and this one is drawn
from its merged pull requests and the Wave 1 closeout.

A8 item 4 has CI run the wave tier's list on linux/amd64. Its first run
timed out on `internal/conformance`, which needs about 1,490 CPU-s under
`-race`, more than one test binary gets on a 2-core runner within `go
test`'s ten-minute timeout. Under R-W1-4, #252 (merged as `44ece575`)
splits that package in `ci.yml` alone: the wave job runs `gate.sh wave`
with the package's tests skipped, then `.github/scripts/conformance.sh
run`, which runs each test in its own invocation and `TestConformance`
once per area. The macos job does the same after `go test -race ./...`.
A5's two tiers, AGENTS.md's tier rules and every timeout are unchanged,
and no larger runner was bought. #249 (`3d13240c`) cleared the
shellcheck findings the same job's sibling found in the gate's scripts.
The wave job's dispatched run 39885052223 and the macos job's
39952978385 are green. The ADR-013 side is
[ADR-013/W1-4b.md](../ADR-013/W1-4b.md).
