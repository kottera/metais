# ADR-010 — W2-4: the release procedure and release.yml (A8 item 2)

**2026-10-23, PLAN-2026-10-metais-public W2-4.** `docs/dev/release.md`
is the release procedure of A8 item 2. It tags in its own clone, runs the
builder twice and compares `dist/`, attaches `dist/` to a draft GitHub
release, and pushes nothing. `release.yml` pushes the tag after Ed's
approval. The builder is unchanged. Its new `verify` subcommand checks a
draft's downloaded assets against `SHA256SUMS` and `buildline.Shipped`
for `release.yml`, and shares the reading of `SHA256SUMS` with the formula
generator of A8 item 3.
