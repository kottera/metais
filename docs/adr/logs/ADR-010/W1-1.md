# ADR-010 — W1-1: the render pipeline in internal/render behind one entry point

**2026-10-21, PLAN-2026-10-metais-render-seams W1-1**, Amendment A7 items
2, 3 and 10. ADR-005 D13's phases left `internal/cli` for
`internal/render`, in the files the plan's §5 table names, and `render`
and `test` now run them through `render.Run`.

- **Item 2.** `render.Run(Options, Emitter)` plans and checks the paths,
  runs the emitter's phase 3, produces, and, when no finding fails the
  render, selects `--only`'s file from the whole render and emits it.
  `internal/cli/render.go` keeps the flags, refusals, help, the result
  records and the choice of emission: the destination check and commit,
  the archive, or one file's bytes, each a function as before. `test`'s
  emission holds each file in memory for its comparison, and `test`
  keeps `parseTemplates`, its parse of its template outputs' templates
  before any example runs. The command's `fault.Set` reaches the
  pipeline as `Options.Seams`, since D13 item 2's tripwire refuses a
  `Faults` key anywhere in `internal/cli`; `internal/render` names no
  fault constant.
- **Item 3.** `planned` is `render.File`, its bytes unexported. The
  record methods the command reads are `File`'s, and `content` is
  `(*File).Open`.
- **The seams Wave 2 fills** have their final names: `runStages(c
  *Staging, f *File)`, holding the CRLF conversion then validation;
  `produce(c *Producing, plan)`; and `walk`, the depth-first walk of the
  plan in planning order that the placement map and rendering share.
- **Item 10.** `Run` alone constructs the `template.Renderer` and sorts
  the top-level files, and findings are made in the order they were: the
  plan's, the destination's, the schemas', then phase 4's. The one
  goroutine is still `(*File).Open`'s pipe for a container.
  `output.declaration.validate_kind` is named in `internal/finding`,
  because `internal/author` is imported only by `internal/cli`; author's
  `CodeValidateKind` is that name.

The relocation is its own commit, before the entry point's. The unit
tests of the code that moved moved with it: `TestAssetBytesStreamed`
(now through `Run`), `TestContainerEntryBoundary`,
`TestRenderCommitAbortsAFailedWrite`, `TestPathRefusal` and `TestCRLF`.
