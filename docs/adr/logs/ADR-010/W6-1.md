# ADR-010 — W6-1: fault.PackMapOrder

**2026-10-20, PLAN-2026-10-metais-v1 W6-1.** D13 item 2 gains
`fault.PackMapOrder`, bit `1 << 9`, the bit the wave 6 brief allots to W6-1,
at `internal/author`'s seam, `PlanPack`: it puts a package's entries in the
order of a Go map built from them. It is the control of pack's byte
identity, as `MapOrder` is a render's: `TestPackDeterminism` packs
`aut/pack`'s source twenty times under it and fails if every pack matches.
`MapOrder`'s seam stays `internal/template` alone, since a fault has one
seam, and nothing a render's map order touches reaches pack's bytes.
