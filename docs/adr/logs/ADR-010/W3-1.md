# ADR-010 — W3-1: internal/render reaches hostfs only through CheckPaths, and holds one go statement

**2026-10-21, PLAN-2026-10-metais-render-seams W3-1**, Amendment A7 item
11 and D2 item 2. The two tripwires A7 item 11 adds to D2 item 2's table
are in place.

- **The layering rule.** `internal/guarantees/layers.json` holds a
  `single-entry-point` rule: `internal/render` reaches `internal/hostfs`
  only through `CheckPaths`. The kind's `function` names a function of the
  importing package, inside which any reference is allowed, so it could
  not say this: the entry point here is a function of the imported
  package. `layers_test.go` gives the kind a second form, `through`, in
  place of `function`: every reference the package makes to the imported
  one is a call of `through`, or sits in that call's arguments outside a
  function literal, which is code of its own the call may run. So
  `hostfs.WithFaults` as `CheckPaths`'s option is allowed, and a write in
  the check function it is handed is not. A rule names one or the other,
  never both. `internal/render/sink` is a package of its own and is not
  bound. The control module, `testdata/layers`, keeps the exception once
  and breaks the rule three times: a write inside the literal, a write in
  a stage, and `CheckPaths` named without a call; its `internal/render/sink`
  writes, and is not flagged.
- **The one goroutine.** `goroutines_test.go`'s `TestRenderOneGoStatement`
  holds the release files of `internal/render` and its subpackages, over
  every target, to exactly one `go` statement, in `producer_assembled.go`
  (A6 item 1), naming each other one it finds and the absence of that
  one. Its control feeds the check the one, one outside `internal/render`,
  none, a second in the file, one in a sink and one in another file of
  `internal/render`.
- **Red first.** On scratch commits that never merged, a
  `hostfs.RemoveFile` call in the `crlf` stage turned `TestLayers` red on
  every target, and a `go` statement in the archive sink's `Close` turned
  `TestRenderOneGoStatement` red, each naming the line.
