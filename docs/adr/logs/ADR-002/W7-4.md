# ADR-002 — W7-4: the log completed from the plan's wave verdicts — Wave 2's profiles, canonical form and version, and Wave 3's stated spelling rule

**2026-10-20, PLAN-2026-10-metais-v1 W7-4.** Plan §8 and §9 name ADR-002
in Waves 2 and 3. This log recorded W2-16 (D4 to D7 and D10) and W3-1
(D1, D9 and D11). It did not record the rest of Wave 2's D2 to D10, or
Wave 3's corrective W3-1F. This entry records them from the plan's
verdicts and the waves' closeouts
([wave 2](../../../briefs/brief-plan-2026-10-metais-v1-wave2.md),
[wave 3](../../../briefs/brief-plan-2026-10-metais-v1-wave3.md)).

**Wave 2.**

- **D2, the YAML profile:** W2-7
  ([#32](https://github.com/kottera/metais/pull/32)) landed
  `internal/yamlx`, which enforces the profile over `yaml.v3` node trees,
  with `FuzzYAMLProfile`. Raw NEL, LS and PS are refused, which is the
  stricter of the readings the ADRs allow.
- **D3, the JSON profile, and D9, the canonical form:** W2-6
  ([#25](https://github.com/kottera/metais/pull/25)) landed `jsonx.Parse`,
  the strict reader with positions, and `jsonx.Canonical` through
  `gowebpki/jcs`, checked against RFC 8785's examples, with
  `FuzzJSONParse`.
- **D8, how the tool states what it implements:** W1-7
  ([#9](https://github.com/kottera/metais/pull/9)) landed
  `version.Implements()`, which is `["1.0"]`. W2-1
  ([#22](https://github.com/kottera/metais/pull/22)) landed `metais
  version`, which prints D8's content, and its `--json` document validates
  against `metais.version/1`.

**Wave 3: the canonical form's large integers.** Plan §9 ruled that ADR-003
D8 item 5's large-integer refusal keeps its reach by spelling. The tool
reads back the canonical form it writes for every number within
±(2^53−1). W3-1F ([#57](https://github.com/kottera/metais/pull/57))
states the rule beyond that range as MTS-MAN-023, with three `man/`
vectors. RFC 8785's integer spelling of a larger canonical number is not
accepted as input, and `maximum: 11e17` opens. Compiled files are compared
as bytes, so no package becomes unopenable.

**Wave 6:** the manifest and YAML-profile cases of ADR-009 D17 item 5
landed in W6-9 ([#129](https://github.com/kottera/metais/pull/129)), which
ADR-006's, ADR-009's and ADR-011's logs record.
