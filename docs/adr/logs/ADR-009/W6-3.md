# ADR-009 — W6-3: the SC7 harness's full reach, and no case exits through a panic

**2026-10-20, PLAN-2026-10-metais-v1 W6-3.** D16 item 1's harness now
reaches everything it lists. `TestHostIsolation` builds the release binary
(`-trimpath`, release tags, never `-race`) and runs every vector of the
suite under it. Every case runs twice:

- with its paths relative to the working directory;
- with them absolute, from a working directory outside the work directory.

Each run is in both environments. Environment A carries the further
variables and the decoys of the working, home and temporary directories.
In the absolute-path run every package the case names is then run through
`ls --recursive`, `read` of every entry, `outline` of every Markdown entry,
`grep` over every entry, `schema`, `extract`, and `render` with `--dry-run`
and to standard output, each in JSON and in human form. Each reading set
is run once per package and limits, and each rendering set once per
package, inputs and render time. Check 2 searches every stream of both
environments for the host name, the user name, the case's temporary root,
the real home directory and the checkout. Check 3 compares every process's
exit status as well as its bytes.

The harness found no leak in the release build: no violation over the
suite on darwin/arm64 with go1.26.9.

- **D18 item 2 was pinned red first.** The fake's `panic` and `fatal`
  faults exit through a Go panic and through a stack overflow. Before the
  crash check, each of their four rows failed the self-proof: the runner
  reported only `exit 2: the tool crashed or reported an internal error`
  (cli) and `the driver exited 2` (exec), never that the process crashed.
  The runner now reads the Go runtime's traceback from standard error, a
  driver's included, and fails the step on the `crash` check. A recovered
  panic, which the tool reports as an internal error, is not a crash.
- **Check 2's self-proof** is the `host-path` fault, a fake that prints its
  working directory, through both adapters. A host or user name no longer
  than three characters is not looked for. Nor is one that the tool's own
  help, the registry's messages or the vector's own files hold, since a
  scan cannot tell it from that text.
- **Every canary of D16 item 2's table is caught under the full harness**,
  on its own channel. The `path` canary is caught by check 2 as well as by
  check 1.
