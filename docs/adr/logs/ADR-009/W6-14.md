# ADR-009 — W6-14: the SC7 harness's every-vector run fits its package timeout

**2026-10-20, PLAN-2026-10-metais-v1 W6-14.** D16 item 1's harness runs
in every `go test` over every vector with the release build, as ruling
R-W6-3 keeps it. That covers environment A's further variables and decoys,
both path modes, checks 1 to 4 and the crash check. On linux,
`internal/conformance` timed out in it. Each of its 10,992 processes
started through a race-built stub that slept a second at exit. ADR-011's
log for W6-14 records the stub's fix. Nothing the harness runs or checks
changed. On a 12-core linux host at `-race -parallel 4`, the run went from
23 minutes 26 seconds to 53 seconds, and its CPU time from 835 s to 395 s.
