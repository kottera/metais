# ADR-009 — W7-4: the log completed from the plan's wave verdicts — the limits table, Wave 2's parser bounds, and Wave 3's checks at open

**2026-10-20, PLAN-2026-10-metais-v1 W7-4.** Plan §7 to §12 name ADR-009
in every wave from 1 to 6. This log recorded Wave 1's tripwire (W1-4),
Wave 2's `hostfs` (W2-5), Waves 4 to 6 and the canaries. It did not
record Wave 1's limits table, Wave 2's parser and pattern bounds, or Wave
3 at all. This entry records them from the plan's verdicts and the waves'
closeouts
([wave 1](../../../briefs/brief-plan-2026-10-metais-v1-wave1.md),
[wave 2](../../../briefs/brief-plan-2026-10-metais-v1-wave2.md),
[wave 3](../../../briefs/brief-plan-2026-10-metais-v1-wave3.md)).

**Wave 1: D3, D4 and D12.**

- **The limits:** W1-3 ([#13](https://github.com/kottera/metais/pull/13))
  landed `internal/limits`. It holds D3's table exactly and D4's lowering
  rules. A raise, an unknown name and a malformed value are each refused
  as `limit.invalid`.
- **The environment:** W1-1 ([#8](https://github.com/kottera/metais/pull/8))
  landed `internal/hostenv.Isolate`. It reads `NO_COLOR`, then calls
  `os.Clearenv` and sets `time.Local` to UTC. It also holds `IsTerminal`.
  On windows, `IsTerminal` calls `syscall.GetConsoleMode`, because W1-4's
  import rule found that `golang.org/x/sys/windows` imports `net`.

**Wave 2: D5 to D7, D9 item 6 and D10, as libraries.**

- **The container:** `internal/zipfmt`'s strict reader, W2-4
  ([#24](https://github.com/kottera/metais/pull/24)), as ADR-001's log
  records.
- **Patterns:** `internal/regexprofile`, with D10 item 6's translation
  table and `FuzzRegexProfile`, in W2-10
  ([#34](https://github.com/kottera/metais/pull/34)). W2-10 also landed
  the closed schema compiler. It compiles the schema files from the
  package's own tree, so a `$ref` resolves only inside the package (D9
  item 6). ADR-010's log records its W2-10 entry. `schema-work` was not
  counted until W6-10.
- **D10 item 4's Markdown bound:** W2-9 measured goldmark as roughly
  quadratic on cmark's pathological cases. Plan §8 ruled, under the
  stricter rule, that the bound stands whole. The outline is METAIS's own
  linear reading, and goldmark leaves the module (ADR-010 Amendment A3).
- **`hostfs`:** the verification round found that `RemoveCreated` trusted
  a reusable inode number, and so removed another party's file on linux.
  W2-5F ([#40](https://github.com/kottera/metais/pull/40)) proves
  ownership with a handle held from creation. It first ran on linux in
  Wave 3.

**Wave 3: D3's package limits, D5, D6, D9 and D11, at open and in the
engine.**

- **Opening:** W3-1 ([#53](https://github.com/kottera/metais/pull/53))
  applies the package limits, the reading checks and entry confinement
  when a package is opened. Chapter 14 states them, and the first `sec/`
  vectors prove them. At least one committed hostile package per
  `package.container.*`, `package.name.*` and `package.digest.*` code is
  refused by `inspect`.
- **The engine:** W3-3 ([#48](https://github.com/kottera/metais/pull/48))
  charges D11 item 2's costs to the meter. W3-4
  ([#46](https://github.com/kottera/metais/pull/46)) charges this ADR's
  costs to the standard filters.
- **Schema compile cost:** Wave 3 found that jsonschema v6's `Compile` is
  quadratic on a hostile schema. Ed ruled Amendment A1
  ([#76](https://github.com/kottera/metais/pull/76)), and W6-5 implements
  it, as recorded above.

**A result weaker than it reads** (plan §10). The `env`, `cwd` and `path`
canaries' red runs are recorded in this log within each squashed pull
request, not as earlier commits on `main`.
