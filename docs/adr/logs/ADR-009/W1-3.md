# ADR-009 — W1-3: the baseline scorecard, and a session's own spilled output is no memory

**2026-10-21, PLAN-2026-10-metais-ux W1-3.** The baseline scorecard ran
every scenario on Opus, Sonnet and Haiku through the runner of Amendment
A8, and is published as `docs/ux/scorecard-2026-10-21-baseline.md`. One
isolation check was corrected. `no-memory-read` recorded C4-what-it-needs
opus invalid, because the session read back a tool output that Claude
Code had spilled to `.claude/projects/<project>/<session>/tool-results/`
beneath the session's own `HOME`. That `HOME` starts empty, so the file is
the session's own output. The check now passes such a path, and still
refuses the same path beneath another `HOME` and a memory directory
beneath the session's own. `TestSpilledToolOutput` holds the run's call,
and was seen red against the old check. The correction uses no symbol
outside A8's allowance.
