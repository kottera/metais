# ADR-009 — W6-9: the hostile manifest corpus

**2026-10-20, PLAN-2026-10-metais-v1 W6-9.** D17 item 5's cases are each a
vector of one defect (R2-178), filed under the area of the first statement
it proves (ADR-011 D16 item 2):

| Case | Vector |
|---|---|
| billion laughs | `man/hostile-billion-laughs` |
| a single alias | `man/hostile-alias` |
| a merge key | `man/hostile-merge-key` |
| `!!python/object` | `man/hostile-tag-python` |
| `!include` | `man/hostile-tag-include` |
| 10,000-deep nesting | `sec/manifest-deep-nesting` |
| a multi-document file | `man/hostile-multi-document` |
| duplicate keys | `man/hostile-duplicate-key` |
| over `manifest-size` | `sec/manifest-over-size`, at a lowered limit |
| a million-digit number | `sec/manifest-million-digit-number` |
| `${HOME}`, `$HOME`, `%USERPROFILE%` and `~` | `sec/manifest-strings-literal` |
| an unknown major version | `ver/hostile-unknown-major` |

- The cases refused from class `refused` findings (`limit.package`, the
  version gate) are tagged `security`, and their open step runs through
  every command that opens a package. The YAML profile's cases are refused
  with class `content` findings, and `check` then also reports
  `report.step_skipped`, as MTS-AUT-002 requires, so they cannot give the
  same findings through every opening command as ADR-011 D16 item 3 asks.
  They are proved through `inspect` and are not tagged `security`, and the
  conflict is a finding for Ed.
- `sec/manifest-strings-literal` renders: every manifest string field, a
  schema file's string and the package's entry names hold the four
  sequences, and the expected tree holds them as written. The A/B run's
  differing `HOME` would also show an expansion. `name`, `version`,
  `metais` and `license` admit none of the four by their grammars, and a
  URI admits only `$HOME` and `~`.
- A Liquid expression cannot hold `}` (the output ends at the first one, as
  in Shopify Liquid), so `${HOME}` appears in a template's raw text and in
  `when`'s string, but not in a `{{ }}` string literal.
- The deep-nesting and million-digit manifests are written by
  `internal/vectorgen/manifest_test.go`, which also proves each has one
  defect. They depend on nothing else in the tree, so they have no merge
  driver and no `regenerate.sh` step.
- D17 item 12's pairs: `sec/manifest-size-bound`,
  `sec/manifest-number-length`, `sec/manifest-value-depth`,
  `sec/schema-number-length` and `sec/schema-value-depth`. No member of a
  1.0 manifest is a number, so the manifest's at-the-bound number is
  refused by the schema as an unknown member, after the limit lets it
  through.
- MTS-MAN-024 states that the YAML profile is judged as written, with no
  alias expanded. MTS-SEC-034 states that a package's strings are data.
  MTS-SEC-035 states that `value-depth` and `number-length` are enforced
  while parsing.
