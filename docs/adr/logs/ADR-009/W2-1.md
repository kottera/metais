# ADR-009 — W2-1: A11, the site's build step's host access

**2026-10-23, PLAN-2026-10-metais-public W2-1.** Amendment A11 is written,
and the site's build step, `internal/tools/site`, uses exactly the symbols
its item 1 names.

- **The allow-list.** `internal/guarantees/hostfacts_test.go` gains the
  build step's entry, for its own package only, with
  `siteBuilderSymbols`: `os.Environ`; `os.Lstat`, `os.Mkdir`,
  `os.MkdirAll`, `os.ReadDir`, `os.ReadFile`, `os.RemoveAll`,
  `os.Rename`, `os.WriteFile` and `path/filepath.WalkDir`;
  `os.MkdirTemp`; and `os.Args`, `os.Stdout`, `os.Stderr` and `os.Exit`.
- **The rules.** `TestModuleAllowListIsR2143` pins the entry and spells
  out its symbols. `TestSymbolRule` refuses them in the converter beneath
  the build step (`internal/tools/site/mdhtml`), in a sibling named like
  it and elsewhere, and refuses inside it the environment's other readers
  and setters, the clock and the zone, the other file functions, the
  temporary directory's name, the working directory, standard input, the
  host name, the process, the home directory, `os.StartProcess`, the
  platform, `os/user` and a random source.
- **`layers.json`.** The `only-referrers` rule names
  `internal/tools/site`, and the `never-depends` rule's reason names
  A11 item 3. `TestLayersControl`'s fixture gains the build step's `main`
  package, which may refer to `os.Stdout`, and its converter, which may
  not and which the fixture's binary imports: both are reported.
