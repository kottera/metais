# ADR-009 — W1-2: the UX scorer takes none of A8's allowance

**2026-10-21, PLAN-2026-10-metais-ux W1-2.** The scorer landed as
`internal/tools/ux/score`, with the transcript reader it shares with the
runner, `internal/tools/ux/streamjson`, and the scrub,
`internal/tools/ux/scrub`. As Amendment A8 item 4 requires, none of the
three refers to a host symbol. The runner opens each run's directory and
each fixture's source with `os.DirFS` and hands them in as `fs.FS`s.
The reader, the scorer and the scrub work on what they are handed, and
start nothing. `TestNoHostFacts` holds them to that with the module's
other packages, because A8's entry covers `internal/tools/ux` alone and
not the packages beneath it. Its rule case "the scorer beneath the UX
runner reads the clock" already refuses the clock in `score`. The
runner's own use of the scorer and the scrub (`-scorecard`, `-scrub`,
and the scorecard a set prints) uses only the symbols A8 item 1 lists:
`os.DirFS`, `os.ReadFile`, `os.WriteFile`, `os.MkdirAll` and `os.Lstat`.
A8 needed no change.

The same item added the runner's `writes-inside-run` isolation check (Ed's
ruling, 2026-10-21): the set's directory outside a run's is listed before
and after its session, and a session that changed it is recorded invalid.
The listing uses only `os.DirFS` and `os.ReadFile`, which A8 item 1
already allows.
