**2026-10-21, PLAN-2026-10-metais-ux W1-1.** Amendment A8 landed with the
runner it allows, `internal/tools/ux`. The module allow-list gains one
entry for that package alone, with exactly the symbols the runner uses.
`TestNoHostFacts` listed those symbols when it was first run over the
runner without the entry. The fixed list keeps the entry from growing
along with `hostSymbols`, as A2's does for the release builder.
`TestModuleAllowListIsR2143` pins it, with the entry's `beneath` off, so
the scenario reader `internal/tools/ux/scenario` and the scorer W1-2 adds
get none of it. A2's `never-depends` rule already held `cmd/metais` away
from `internal/tools/...`. `TestLayersControl`'s fixture module now proves
the rule sees the runner: its binary imports a package beneath the
runner, and the rule refuses it. Each new case was seen red against a
scratch change before it passed:

- the layering control, with the rule narrowed to the release builder;
- the symbol rule's refusals, with the entry widened to the packages
  beneath it and to the clock, environment, working-directory and
  host-name symbols A8 item 2 refuses.
