# ADR-009 — W6-2: SC7 scans every package a pack step writes

**2026-10-20, PLAN-2026-10-metais-v1 W6-2.** D16 item 1 lists among the
streams scanned the raw bytes and every decompressed entry of a package
`pack` wrote. The conformance runner now scans every file a `pack` step
creates or changes in the work directory as a package. It scans the raw
bytes and every entry inflated, and each zip inside an entry, three levels
deep, under checks 1 and 2. Check 3 already compares the written files
between environments A and B.

A pack step writes a package and nothing else, so a file the scan cannot
read as a package from its first byte is itself a failure. The scan of
other written files inflates only what begins as a zip, so it could not see
the entries of a package written behind a prefix that a zip reader reads
past.

The runner's self-proof shows the scan sees a leak. The fake gained `pack`
and the fixture vector `fix/pack`. Its fault `sentinel-pack` plants the
sentinel in a deflated entry of the packed package, where its raw bytes do
not show it. `sentinel-pack-prefixed` does the same behind a prefix. Each
must fail the sentinel check through both adapters. Before this change,
`sentinel-pack-prefixed` passed it. `TestScanPacked` pins each case of the
scan, and that the planted sentinel is absent from the raw bytes.
