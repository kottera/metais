# ADR-005 — W6-1: pack's atomic replace through hostfs

**2026-10-20, PLAN-2026-10-metais-v1 W6-1.** `hostfs.FileOut` is D14's
one-file write for pack (ADR-007 D7 item 5): a temporary file named by
`TempName`, D14 item 2.1's name, created exclusively in the target's own
directory and held to Amendment A1 item 6's ownership rule, since it removes
only that file and only while its handle's `Stat` proves it is the one it
created. A1 item 5 says a render writes no temporary file beside a target;
pack is not a render into a directory, and ADR-007 D7 item 5 names this
file. The target is examined with `Lstat` and never opened (D15 item 4); a
regular file is replaced with `RenameReplace`, D14 item 2.2's rename, and an
absent one is created with `RenameNoReplace`, item 1.4's. The file is
synced before the rename, which ADR-007 D7 item 5 asks for and D14 item 3
does not.
