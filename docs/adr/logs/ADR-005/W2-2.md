# ADR-005 — W2-2: D13 item 4's bound holds after D10

**2026-10-21, PLAN-2026-10-metais-render-seams W2-2.** D13 item 4 bounds
the text a render holds by ADR-009's per-output and total output size
limits, and D10's CRLF conversion, which can make a file up to twice as
long, now runs inside that bound: the conversion's growth is charged to
`output-size` and `output-total` with the bytes the file rendered, and a
file it takes beyond either is refused with `limit.exceeded.output` before
D11 validates it. Before, `--limit output-size=700` on a file rendering 601
bytes and converting to 902 wrote 902 bytes with exit status 0. D11 still
reads the final bytes of every file that did not breach, and reports every
finding. MTS-SEC-010 now says plainly that an output's bytes are the bytes
the render writes; the vectors `sec/output-size-crlf` and
`sec/output-total-crlf` prove it.
