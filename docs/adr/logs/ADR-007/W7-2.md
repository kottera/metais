# ADR-007 — W7-2: `check` refuses a literal output path a render would refuse

**2026-10-20, PLAN-2026-10-metais-v1 W7-2.** `check` accepted an output
path the manifest writes literally that every render refuses, such as
`path: ../escape.txt`: D2's steps never held a literal path to ADR-005
D12's portable-path predicate, which a render applies to every path it
plans. That is no confinement breach, since `render` and `test` refuse the
path before anything is written, but it is an acceptance disagreement:
`check` exists to tell an author whether a package will render. The plan
orchestrator ruled, in the
[Wave 7 brief](../../../briefs/brief-plan-2026-10-metais-v1-wave7.md)
under plan §4's stricter-rule convention, that `check` refuses such a path
with the refusal the predicate gives.

- **The change.** D2 step 4's "manifest paths" part now holds every
  output path written without Liquid markup, and every template's default
  path, at every depth of a container to `container-depth`, to the
  predicate (`unitext.CheckPath`), and reports each refusal with the
  finding a render gives it: the `output.path.*` codes, and
  `limit.package` for `path-length` and `path-depth`. An asset's or a
  mirror's literal destination other than `.` is held to it too, as the
  directory every file it writes lies beneath, and is reported by its own
  path. The literal paths of the declarations with neither `when` nor
  `for_each`, which every render plans once, are held together to D12
  item 6's collisions, in the output directory and in each container's
  entries but a reserved one. A path only a render can know is still the
  render's. The finding mapping moved from `internal/cli` to
  `internal/template` (`PathFinding`, `CollisionFinding`), so `check` and
  `render` give one finding for one refusal. `pack` runs `check`, so it
  refuses such a package too.
- **The specification.** MTS-AUT-080 states it, and the vector
  `aut/check-output-paths` proves it. `check`'s declared refusals gain the
  `output.path.*` codes, and the help goldens were regenerated.
- **Pinned false first.** The vector fails against a `metais` built from
  `main` before the change (`ok is true, expected false`; 9 findings
  expected, none given), and `TestCheckOutputPaths` is its negative test.
