# ADR-007 — W6-1: pack, check then test then the deterministic write

**2026-10-20, PLAN-2026-10-metais-v1 W6-1.** D7 landed whole as `metais
pack` (`internal/cli/pack.go`, `internal/author/pack.go`). It opens the
operand as every opening command does and refuses a packed package that
opens with `usage.not_a_source_directory` (the stricter reading, unpack's
precedent, which the plan orchestrator confirmed); runs `author.Check`,
stopping on any error with every finding; runs the examples through test's
own code (`runExamples`, now shared by `test` and `pack`), stopping on a
failure with every finding of both; and reports warnings without stopping.
`--fail-on warning` (R2-134) makes a warning stop it.

- **Item 3.** The entries are the source tree the open read, which already
  holds exactly D7 item 3's set: the quiet list is never an entry, another
  top-level name is check's `package.layout.not_packed`, and a dotfile
  inside a layout tree is an entry. `.compiled/` is the open's derivation
  and the digest file of them all.
- **Item 4.** `author.PlanPack` hashes every entry once and the writer reads
  each again, refusing bytes that changed (`package.not_readable`, reason
  `changed`), and the plan's package digest must be the open's. The bytes
  are zipfmt's `WriteParts`, every method auto. `TestPackDeterminism` holds
  them equal across GOMAXPROCS, other modification times and modes, and a
  fresh process under a hostile zone, locale, umask and GODEBUG; its
  control is `fault.PackMapOrder` (bit 9).
- **Item 5.** `hostfs.FileOut` writes `.metais-tmp-<h>` exclusively, syncs
  it and renames it over the target, a no-replace rename when nothing stood
  there. A target that is not a regular file is
  `output.destination.nothing_written` with reason `is_directory` or
  `not_regular_file`, a link included, since a link is never written
  through; a missing directory is reason `not_found`, a leftover temporary
  file reason `exists`, a file above `output.destination.not_directory`.
  An output in a layout tree is the new `output.destination.in_package`;
  the stricter security reading also refuses the source's `metais.yaml`
  itself, which item 5 does not name and which a replace would destroy.
  Identity, not path text, decides both.
- **Item 6, and `--dry-run`.** D9's synopsis lists `--dry-run` and no ADR
  says what it prints; it is read as `unpack --dry-run` is: everything but
  the write, refused exactly when pack would be before writing, with the
  result `dry_run` true and the entries listed in human mode.
