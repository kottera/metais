# ADR-007 — W2-6, `init --minimal` and `init --html` (Amendment A1)

**2026-10-22, PLAN-2026-10-metais-ux Wave 2.** Amendment A1 is
implemented.

- `author.Scaffold` and `author.Init` take an `author.Form`, whose
  `Minimal` and `HTML` choose among the four scaffolds. With neither, the
  scaffold is D1 item 4's, byte for byte: its golden files did not change.
- The golden files of the other three forms are under
  `internal/author/testdata/scaffold/html/`, `minimal/` and
  `minimal-html/`, each for `acme-report`. `TestScaffoldGolden` writes
  every form's with `-update`, which `regenerate.sh` already runs, and the
  existing `.gitattributes` pattern `internal/author/testdata/scaffold/**`
  gives them their merge driver.
- `TestScaffoldMinimal` holds item 1: one input, `data`, one template,
  and no greeting and no example. `TestScaffoldHTML` holds item 2: the
  output declares `escape: html`, and its template writes the input into
  a `<script>` through `json_script` and never through `json`. Each was
  seen red with the change undone: with `escape: html` dropped from the
  manifest, with `json_script` written as `json`, and with an example added
  to the minimal scaffold.
- `TestInitForms` is item 4: for each form, `init`, `check` with no
  finding, `render --sample --out <new dir>` and `pack`. It was red,
  `usage.unknown_flag`, before `init` declared the flags.
- Spec appendix B's note on `init` names both flags. Chapter 13 does not
  describe the scaffold, so it does not change.
