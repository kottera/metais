# ADR-007 — W7-1: a write that stops after unpack has written gets its vector

**2026-10-20, PLAN-2026-10-metais-v1 W7-1.** MTS-AUT-027's
`output.destination.write_failed` has a vector, `aut/unpack-write-stopped`.
It unpacks aut/unpack's package into an existing, empty directory under
ADR-011 A6's `file_size_limit` of 300 bytes. The 228-byte
`inputs/report.schema.json` is written, and the 394-byte `metais.yaml` is
refused. The finding lists the one file written, with reason `io_error`,
and the directory holds it and nothing else. No existing setup could reach
the case; ADR-011 A6 item 5 says why. Its `package.metais` is vectorgen's,
packed from the same source directory as aut/unpack's.
