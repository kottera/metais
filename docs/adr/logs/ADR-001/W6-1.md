# ADR-001 — W6-1: D4 through pack, and the Writer conformance statements

**2026-10-20, PLAN-2026-10-metais-v1 W6-1.** `metais pack` writes through
D4's one writer, `zipfmt.WriteParts`, with D4 item 7's entry order and
every method auto. The *Conformance* section's Writer and host-independence
statements are chapter 2's §2.7, MTS-PKG-034 to 040, with vectors:
`aut/pack` (the entry set, order, the encoder-independent methods of an
empty and an incompressible entry, content byte for byte, the package
opening, and environments A and B packing the same bytes) and
`pkg/pack-round-trip` (pack → unpack → pack, by entries and so by package
digest, for the scaffold and a fixture). Byte identity within one build,
across GOMAXPROCS, modification times, modes and a hostile host, is
`internal/guarantees`' `TestPackDeterminism`; identity across targets is
the matrix act's (SC5), which a sandbox cannot run.
