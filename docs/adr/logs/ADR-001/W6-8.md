# ADR-001 — W6-8: the Conformance list's container, name, layout and digest cases, and a zip64 extra field refused as zip64

**2026-10-20, PLAN-2026-10-metais-v1 W6-8.** The reader now refuses a zip64
extra field as `package.container.zip64`, as D1 item 2 and MTS-PKG-004
require. It used to skip a central directory header's extra field and
report only `package.container.extra_field`. It now reads that field, at
most 65,535 bytes inside a central directory it has already bounded. When
a record with header ID 0x0001 is among its records, it reports `zip64`
beside `extra_field`. `TestOpenRefuses` was red with the case before the
fix.

Every case of the Conformance list's container, name, layout and digest
lines is a vector, beside ADR-009 D17's corpus:

- **The D1 fields:** `pkg/version-needed`, `flag-bit-6`, `flag-bit-13`,
  `flag-reserved`, `flag-utf8-clear`, `method-deflate64`, `method-lzma`,
  `method-zstd`, `method-aes`, `mod-time`, `mod-date`,
  `extra-field-unicode-path`, `zip64-extra-field`, `version-made-by`,
  `internal-attributes`, `external-attributes`, `file-comment`,
  `disk-number-start` and `end-disk-number`.
- **Structure and data:** `pkg/gap`, `overlap-quoted`, `central-order`,
  `local-*`, `zip64-end-record`, `crc-wrong`, `size-more-data` and
  `deflate-truncated`. `sec/entries-packed` is the entry count above the
  limit.
- **Names:** `pkg/name-*`, including `name-zero-width-space`,
  `name-private-use`, `name-unassigned`, `name-kelvin` and
  `name-case-collision-prefix`.
- **Layout:** `pkg/compiled-missing-manifest`, `compiled-missing-schema`
  and `compiled-missing-digests`.
- **Digests:** `pkg/digest-not-listed` and `digest-no-entry`, the missing
  and the extra `entries` key apart. `pkg/compiled-stale` holds a combined
  schema and a references index that both disagree with the sources; both
  are refused in one run. A stale `.compiled/manifest.json` gates the
  version check those derivations follow (ADR-002 D11 item 8), so it is
  not independent of them.

MTS-PKG-045 states what D1 item 2 fixes in the end record and chapter 2
gave no code for. Either disk number other than 0, or two entry counts
that differ, is `field_value`. A total count that is not the number of
headers the central directory holds is `overlap_or_gap`.

The Writer and Host independence lines are `pack`'s (W6-1).
