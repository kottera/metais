# ADR-001 — W7-C7: every package begins with the specification's README.md, stored (Amendment A1)

**2026-10-20, PLAN-2026-10-metais-v1 W7-C7.** Amendment A1 is implemented.
The README text of 1.0 lives once, in `spec/readme/1.0/README.md`. Chapter 2
§2.4.1 carries the same bytes normatively. `internal/specdata` embeds a copy
as `Readme10`. `TestSpecDataMatchesSpec` holds the copy to the file, and
`TestReadmeMatchesChapter` holds the chapter's block to it, with a control
that catches a one-byte change.

- **Items 1 and 4, pack.** `author.PlanPack` takes the declared version and
  writes `README.md` first and stored, then every other entry in byte
  order, so `.compiled/digests.json` is second. `TestPackWritesReadmeFirst`
  reads the written bytes. The name sits at offset 30 and the text at
  offset 39. It was red before the change, and its control,
  `TestReadmeFirstStoredControl`, is red against a writer that deflates
  `README.md` or does not put it first.
- **Item 4, the reader.** `internal/zipfmt`'s order rule exempts a first
  `README.md` and nothing else (MTS-PKG-010). The Archive lists its entries
  in byte order, as every `pkgtree.Tree` does, and gives the file's order
  through `Entries`.
- **Item 5, digests.** Step 6 leaves `README.md` out of the entries it
  checks against the digest file, wherever it lies, so step 7 judges a
  misplaced one. Pack leaves it out of the digest file. Of the committed
  packages, 148 carry a `.compiled/digests.json` byte-identical before and
  after the change, so their package digests did not move.
  `pkg/unknown-top-level` is the exception, because its extra top-level
  entry, `README.md`, is now `NOTES.md`.
- **Item 6, verification.** Step 7's layout stage checks the first entry
  and reports `package.layout.readme` with `reason` `missing`; otherwise it
  reports `not_first`, `compressed` and `altered`, one finding for each that
  applies (MTS-PKG-071, MTS-PKG-072). `TestOpenChecksReadme` and
  `TestCheckChecksReadme` were red against the tool without the check: the
  missing case opened. The vectors are `pkg/readme-missing`,
  `readme-compressed`, `readme-not-first` and `readme-altered`.
- **Item 7, layout.** `README.md` joins the closed top level of a packed
  package. A source directory's top-level `README.md` is ignored silently,
  in `internal/hostfs` and in `loader.OpenFiles`. Unpack does not write it.
  A packed package's `Tree` hides it as well: it is no part of the content,
  and ADR-008 D16 item 4 has a packed package read as its source does.
- **Item 8, detection.** Chapter 2 §2.1 states the key.
  `TestDetectionKey` holds every committed package that opens to it, and
  the missing and misplaced vectors to lacking it.

Every committed package was regenerated by `internal/vectorgen`. The byte
offsets, entry counts and sizes their findings report moved by the README's
local record and central header (505 bytes) or by its size (411). `pack`'s
expected outputs were rebuilt by the tool. Each is its old entries,
unchanged and with the same methods, behind `README.md`.
