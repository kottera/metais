Wave 2 raised one question for this ADR. D8 item 5 refuses a large integer
by its spelling, so `11e17` is accepted while its canonical text is
refused. Plan §9 ruled that the reach by spelling stands, and that a
number the tool writes must be one it reads, within ±(2^53−1). W3-1F
states the rule beyond that as MTS-MAN-023 (ADR-002's log). W3-5F
([#56](https://github.com/kottera/metais/pull/56)) makes sample JSON spell
such a number with an exponent, through `jsonx.EncodeInput` (ADR-007's
log).
