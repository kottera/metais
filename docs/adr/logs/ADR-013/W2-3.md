- **D7 item 5.** The tap's formula is generated from `SHA256SUMS` by `go
  run ./internal/tools/release formula -version <v> -sums <SHA256SUMS>`,
  with a golden test that `regenerate.sh` rewrites. `release.sh` (W2-4)
  pushes what it writes.
- **D7 item 3.3.** A prerelease carries no `spec-*` tag because it may
  implement a draft revision. The builder's rule that lets it is pinned on
  both sides by `TestReleaseRefusesAnUnreleasedRevision`. Every candidate
  from `v1.0.0-rc.1` to `v1.0.0-rc.7` was built under it before
  `spec-1.0` existed.
