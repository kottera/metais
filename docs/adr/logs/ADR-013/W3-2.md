# ADR-013 — W3-2: CI on every pull request and push to main, and the public project's rule (D4 item 3, D5 items 2 and 5)

**2026-10-24, PLAN-2026-10-metais-public W3-2.** Written at the train's
close, 2026-10-26, by W4-3: the item wrote no entry, and this one is drawn
from its merged pull request, #324 (merged as `7ff24d39`), and the Wave 3
closeout.

- **D5 items 2 and 5.** From the flip, `ci.yml` runs on `pull_request`
  (opened, synchronize, reopened and edited, with no branch filter), on
  `push` to `main`, and on `workflow_dispatch` as before. A newer pull
  request run cancels an older one; a push run is never cancelled.
  `TestCIWorkflow` holds the triggers, and went red against the old set.
  #324 was the first pull request CI ran on by `pull_request`.
- **D4 items 2 and 3.** AGENTS.md's "private for now" rule became the
  public project's: everything committed is published, nothing internal
  enters it, and a secret that reaches a pushed commit is rotated.
  `CONTRIBUTING.md`, `docs/dev/release.md`, the workflows' comments and
  `site/site_test.go` stopped describing a private repository. The guards
  that refuse a release or a deploy from a private repository stay.

ADR-010 A8 item 4's side is [ADR-010/W3-2.md](../ADR-010/W3-2.md).
