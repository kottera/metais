# ADR-013 — W4-1: the rehearsal checks a stable release and the released specification

**2026-10-26, PLAN-2026-10-metais-public W4-1.** Under R-W4-1, a fix
to the rehearsal's harness (D7 item 8). It changes no release or site
bytes. The first `rehearse.yml` run against `v1.0.0`, 40312702820, failed
in its harness and not in the release.

- **The pinned install of a release.** For a version with no prerelease
  suffix, `install.sh` with no `METAIS_VERSION` installs that version
  into `~/.local/bin`. The pinned install then wrote the same bytes, and
  `rehearse.sh install` refused because the file had not changed. Each
  install job failed that step and skipped `metais skill` after it. #361
  (`cab4d4e3`) landed the repair while this item was in flight: `install`
  removes the binary before the pinned install, and that install must
  write it again and report the version. Its `TestRehearseScript` cases
  are the proof of that half. This item kept that repair as it is, and
  names the install step for the release it now also checks.
- **The released specification (ADR-011 A8 items 1 and 2).** A new check,
  `rehearse.sh released <tree> <metais>`, reads the revisions that the
  release's `metais version --json` implements. A revision is released
  when the checkout of the release's tag holds a `spec-<M>.<m>` tag for
  it. `actions/checkout` now uses `fetch-depth: 0`, so the tags are
  there, which is also how the site's build reads them. For each released
  revision, the check requires a `/spec/<M>.<m>/` page for every chapter
  of `spec/` at that tag. Each page must serve HTML and must not ask to
  go unindexed. `/spec/` must lead, by the site's refresh, to the latest
  released revision. A release that implements no released revision is
  refused (ADR-011 D5 item 6). A prerelease that implements none passes,
  and only `/spec/draft/` is checked for it. The site builds the draft
  from the release's own `spec/` in every case, so the draft check
  stays as it was. `TestRehearseScript` refuses each of these: a missing
  chapter, a missing contents page, an unindexed page, `/spec/` leading
  elsewhere or missing, a later tag, a release of no released revision,
  and a checkout with no repository.
  `TestRehearseWorkflow` requires the step and the full-history checkout.
