# ADR-013 — W3-6: v1.0.0-rc.1 cut and drafted with nothing pushed (D7 items 3.1 and 8)

**2026-10-24, PLAN-2026-10-metais-public W3-6.** Written at the train's
close, 2026-10-26, by W4-3: the item wrote no entry, and this one is drawn
from its merged pull request, #327 (merged as `ebe5d2ea`), the record it
wrote, and the Wave 3 closeout.

The release procedure's first run as D7 item 3.1 gives it.
`v1.0.0-rc.1` was tagged in a fresh clone only, at `main`'s tip
`7ff24d39`, with no `spec-*` tag, since a prerelease releases no
specification. It was built twice, byte-identical by `diff -r`, and
drafted with the four archives and `SHA256SUMS`. `git ls-remote` showed
nothing pushed. `docs/dev/rehearsal/v1.0.0-rc.1.md` holds `SHA256SUMS`
verbatim. rc.1 was never published: its release run's push of the tag was
refused, because its target's workflows predated #328 and #333 and
`GITHUB_TOKEN` cannot push a workflow change. W3-10 (#335) now refuses
such a target before anything is pushed.
