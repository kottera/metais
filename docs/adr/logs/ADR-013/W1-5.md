# ADR-013 — W1-5: D2 item 2's one exception, the version's maker line

**2026-10-22, PLAN-2026-10-metais-public W1-5.** D2 item 2's exception is
in the binary, under ADR-008 A14: `metais version`'s text output, and so
`metais --version`'s, ends with `METAIS is made by Kottera.`, which names
no product and gives no URL. `--version --json` gains no member;
`internal/cli`'s `TestVersion` holds its bytes. `TestVendorNeutral` holds
every help output and the agent skill to naming neither Kottera nor tera,
so the line stays the one exception.
