# ADR-013 — W3-3: the workflow that runs the rehearsal's checks on a release (D6, D7 item 8, D8)

**2026-10-24, PLAN-2026-10-metais-public W3-3.** Written at the train's
close, 2026-10-26, by W4-3: the item wrote no entry, and this one is drawn
from its merged pull request, #325 (merged as `470c2597`), and the Wave 3
closeout.

`.github/workflows/rehearse.yml`, dispatched with a `version`, runs D7
item 8's checks against a published release on GitHub-hosted runners and
an `ubuntu:24.04` container given only curl. Its eight jobs are brew on
macOS; `install.sh` on Ubuntu, macOS and the container, with and without
`METAIS_VERSION`; `go install` through the proxy and with
`GOPROXY=direct`; the manual route on Ubuntu and macOS; and the site:
every `$id`, the `go-import` pages, a reference page per command and
topic, the specification's pages, the landing and install pages,
`/install.sh` byte-identical to the tag's, and kottera.com. Each route job
checks `metais --version` and `metais skill`. `.github/scripts/rehearse.sh`
holds one subcommand per check. `TestRehearseWorkflow` holds the workflow
to the brief's list, and `TestRehearseScript` runs every check against a
release served locally, and against each defect it exists to find.
`docs/dev/release.md` says how to dispatch it.

Its first run was rc.2's, 40134009587. rc.7's run 40242581308 passed 8 of
8.
