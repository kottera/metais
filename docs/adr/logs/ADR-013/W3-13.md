# ADR-013 — W3-13: install.sh finds the latest stable release by github.com's redirect (D6 item 7)

**2026-10-25, PLAN-2026-10-metais-public W3-13.** Written at the train's
close, 2026-10-26, by W4-3: the item wrote no entry, and this one is drawn
from its merged pull request, #347 (merged as `b49b10fb`), and the Wave 3
closeout.

Under R-W3-4, after rc.6's `install-macos` check got GitHub's anonymous
rate-limit 403. D6 item 7's "the latest release that is not a
prerelease" is now read from `https://github.com/kottera/metais/releases/latest`
without following the redirect: a redirect to a tag is the version, and a
redirect to `/releases` or a 404 is the same "no stable release" refusal,
naming `METAIS_VERSION`. A 403 or 429 is reported as a rate limit, never
as no stable release, and any other answer as itself. The script no longer
names `api.github.com`, and the rest of D6 is unchanged.
`site/install_test.go` covers both sides of v1.0.0 and each answer, and
`TestInstallURLsConstant` refuses `api.github.com/`. CI's install test
serves the redirect as github.com does. `b49b10fb` is rc.7's target. Its
squash body has a paragraph after the `Signed-off-by:`, so git parses no
trailer from it; history was not rewritten, and W3-NB1 prevents the next
one.
