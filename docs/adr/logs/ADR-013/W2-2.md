# ADR-013 — W2-2: the reference pages, the specification's pages, the install page, and the internal-link test (D6, D8 items 2 to 4)

**2026-10-23, PLAN-2026-10-metais-public W2-2.**

- **The reference pages (D8 item 2)** are generated from `metais help
  --json` and `metais skill --print`, as ADR-008 A13 has them, under
  `/reference/`. They are vendor-neutral because the help and the skill
  are, which `TestVendorNeutral` holds.
- **The specification (D8 item 3)** is served at `/spec/draft/`, and each
  released revision at `/spec/<M>.<m>/`, as ADR-011 A8 has it.
- **The install page (D6).** It gives item 1's four routes with their
  commands; item 6's `~/.local/bin`, `METAIS_INSTALL_DIR` and the `PATH`
  line the script prints; item 7's `METAIS_VERSION`; item 9's `metais
  skill`; and item 10's `xattr -d com.apple.quarantine`. It links
  `/install.sh`, which item 3 asks a reader to read first. A site built
  for a release lists that release's archives and their checksums from
  its `SHA256SUMS`. `TestInstallPage` holds each.
- **The site's tests (D8 item 4).** `TestReferencePages` holds each
  reference page to the help it came from. `TestInternalLinks` holds every
  internal link of every page of the built tree, an `href`, a `src` or a
  meta refresh, to a file the site serves, and each fragment to an id of
  its page. It walks the whole tree, so a page a later change adds is held
  as it lands. `TestLinks` pins it false first. The navigation names the
  reference and the specification.
