# ADR-013 — W1-1: the module's go-import pages of D1 item 2

**2026-10-22, PLAN-2026-10-metais-public W1-1.** D1 item 2's module path
is the module's (ADR-010 A8 item 1), and the site carries its two
`go-import` pages at the path D1 item 5 gives them.

- **The pages.** `site/public/metais/index.html` serves
  `metais.org/metais` at `/metais/`, and
  `site/public/metais/cmd/metais/index.html` serves
  `metais.org/metais/cmd/metais` at `/metais/cmd/metais/`. Each carries
  `go-import` with content
  `metais.org/metais git https://github.com/kottera/metais` and a
  `go-source` tag naming the repository's directory and file templates.
  `site/build.sh` copies them with the rest of `site/public/`.
- **The test.** `site`'s `TestGoImportPages` requires, in `site/public/`
  and in the tree `build.sh` publishes, that the pages under `metais/`
  serve exactly the two package paths, that each page's `go-import`
  content is exactly D1 item 2's string, and that each carries one
  `go-source` tag for the same module and repository. It was seen red
  against a page whose `go-import` named the repository with a `.git`
  suffix, and against the `cmd/metais` page removed.
- **Not yet served.** metais.org serves the pages once the site is
  published (ADR-013 D7); until then `go install metais.org/metais/...`
  does not resolve.
