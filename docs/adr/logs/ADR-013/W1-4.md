# ADR-013 — W1-4: the DCO check of D3 item 2, and CI of D5

**2026-10-22, PLAN-2026-10-metais-public W1-4.** D3 item 2's DCO check and
D5's CI land as `.github/workflows/ci.yml`, with the tripwire of D5 item 1.

- **D3 item 2.** `.github/scripts/dco.sh <base> <head>` fails unless
  every commit reachable from the head and not from the base, merge
  commits included, carries a `Signed-off-by: Name <email>` trailer; when
  the head is on the base it checks the head alone. There is no exemption
  list. `TestDCOCheck` runs it over signed, unsigned, address-less,
  non-trailer and merge commits. AGENTS.md's git rules require the
  sign-off, and every commit of this train from this change on carries it.
- **D5 items 1 and 2.** Every job runs on `ubuntu-latest` or
  `macos-latest`. The jobs are item 2's: the wave tier's list on
  linux/amd64, the race-enabled tests and the build steps on
  darwin/arm64, the DCO check, `shellcheck` over the repository's shell
  scripts (fixtures under `testdata/`, the conformance vectors and the
  examples' expected outputs are data, not scripts it runs), and the
  site's build and tests. The install script's tests are a step of the
  `shell` job when Wave 2 writes them. `TestWorkflows` is item 1's
  tripwire.
- **D5 item 5.** `ci.yml` runs only on `workflow_dispatch` while the
  repository is private. Each job was proved by a dispatched run, linked
  on this item's pull request. GitHub dispatches only a workflow on the
  default branch, so the runs followed the merge (R-W1-2).
