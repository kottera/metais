# ADR-013 — W2-13: the tap's README, licence and CI (D1 item 3, D7 item 5)

**2026-10-23, PLAN-2026-10-metais-public W2-13.** Written at the train's
close, 2026-10-26, by W4-3: the item's change is in another repository,
and it wrote no entry here. This one is drawn from its merged pull
request and the Wave 2 closeout.

W2-13 (`01a16924-2655`) merged kottera/homebrew-tap#1 as `3f164193`. It
replaced W2-9, cancelled when W2-6 failed. The tap `kottera/tap` gained a
README naming the formula (`brew install kottera/tap/metais`), the
Apache-2.0 licence, and CI that runs `brew audit --strict`, install and
test on every `Formula/*.rb`, on each push and pull request, on
GitHub-hosted ubuntu and macOS runners, with a read-only token. A pull
request may carry archives under `.github/test-archives/` to test a
formula before its release exists, and CI fails a push to `main` that
carries them. It was proved by test pull request kottera/homebrew-tap#2,
closed unmerged, whose formula is byte-identical to the generator's (W2-3)
for the same `SHA256SUMS`. No formula was on `main` at merge; the first,
`1.0.0-rc.2`, was pushed by `release.yml` on 2026-10-24 (tap commit
`158ccff5`). The audit runs without `--online`, since no release URL
existed when it was written. The merge subject lacks " (#1)"; it is not
renamed.
