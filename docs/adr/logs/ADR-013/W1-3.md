# ADR-013 — W1-3: the community files of D3 item 3

**2026-10-22, PLAN-2026-10-metais-public W1-3.** D3 item 3's community
files are at the repository's root and under `.github/`, for a
contributor outside the train; AGENTS.md keeps the train's own workflow.

- **`CONTRIBUTING.md`** covers building and testing from the `go.mod`
  toolchain line, the generated files with `merge-setup.sh` and
  `regenerate.sh`, what CI runs as D5 item 2 states it (on
  GitHub-hosted runners, and only when dispatched by hand while the
  repository is private, D5 item 5), the DCO and `git commit -s` (D3 item
  2), the order of a change to the format (the specification, its
  vectors, then the tool, in one pull request; where the tool and the
  specification disagree, the tool is wrong), and where to ask.
  Its CI section is true of the jobs W1-4's `.github/workflows/ci.yml`
  has: the wave tier on linux/amd64, the race tests and build steps on
  darwin/arm64, the DCO check, `shellcheck` and the site. The install
  script's tests join the `shell` job in Wave 2, and the section names them
  then.
- **`CODE_OF_CONDUCT.md`** is the Contributor Covenant 2.1, verbatim from
  the Covenant's own repository, with the contact address Ed named under
  R-W1-1, `conduct@kottera.com`.
- **`SECURITY.md`** routes every report through GitHub's private
  vulnerability reporting and names no address (R-W1-1). Its scope is the
  tool's handling of an untrusted package and its inputs (ADR-009,
  specification chapter 14) and the install routes of D6 item 1, and a
  security erratum of the text. It says what to include and what a
  reporter can expect, and promises no response time.
- **The templates.** `.github/ISSUE_TEMPLATE/` holds a bug, a
  specification question or erratum (in `spec/ERRATA.md`'s kinds), and a
  feature request; `.github/pull_request_template.md` names the
  specification-first rule and the DCO sign-off.
- **D2 items 2 to 4.** No community file names tera, and none names
  kottera.com but as the domain of the Code of Conduct's contact address.
  Kottera appears only as the maker, in the Go licence header
  `CONTRIBUTING.md` quotes, and as that contact.
