# ADR-013 — W3-12: the install check reads every shell's not-found, and a set keeps no host PATH or local time (D9)

**2026-10-25, PLAN-2026-10-metais-public W3-12.** Written at the train's
close, 2026-10-26, by W4-3: the item wrote no entry, and this one is drawn
from its merged pull request, #346 (merged as `390f0398`), and the Wave 3
closeout.

Two defects W3-OOB5's I1 and I2 act found in the UX runner, which D9's
scenarios run on.
- **The install check.** `notFound` read only bash's and sh's wording, so
  zsh's `command not found: metais` before an install was read as a
  metais that ran, and golden-install failed a session that installed by
  brew. It now reads bash, sh, dash, ksh, zsh and fish, and only a
  shell's report that names metais. The fixture
  `edited-i1-zsh-not-found-then-brew` was red before the fix, and
  `TestInstallAfterZshNotFound` keeps the negative.
- **The scrub.** A PATH anywhere in a set keeps the runner's placeholders
  and the standard system directories, and every other entry becomes
  `/ux/host`. Sessions run under `TZ=UTC`, and `ls -l` times are
  scrubbed for sets already recorded. A local time printed by another
  command in an older set is not covered, and `docs/dev/ux-testing.md`
  says so.
