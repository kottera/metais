# ADR-013 — W2-1: the site as a METAIS package (D8 item 1), its footer (D2 item 1) and its static files (D1 item 5)

**2026-10-23, PLAN-2026-10-metais-public W2-1.** The site is the package
`site/package`, rendered by `site/build.sh` with the `metais` built from
the commit being built.

- **The build step.** `site/build.sh` runs `internal/tools/site` (ADR-009
  A11), which builds `metais`, exports the package's inputs as JSON, renders
  the package, and adds `site/public`'s files and the schemas. The inputs
  are `help` (`metais help --json`'s result), `skill` (`metais skill
  --print`, as text and as HTML), `spec` (the draft and every
  `spec-<M>.<m>` tag's Markdown files as HTML, ADR-011 A8), `release`
  (the release's version and the archives its `SHA256SUMS` lists, or
  `published: false`) and `tool` (`metais version --json`'s result). The
  package's schemas hold each one, and two of them are generated from
  `docs/cli/schemas/`. The Markdown library is ADR-010 A10's.
- **A release's site.** `site/build.sh --release <version> <SHA256SUMS>
  <out>` is refused unless `HEAD` is the tag `v<version>` and the clone is
  whole. It builds `metais` with the release's build line, which must report
  that version.
- **The pages.** The pages that were under `site/public` are the package's
  templates, around one layout, with their words unchanged. The layout puts
  D2 item 1's footer on every page: METAIS is made by Kottera, with a link
  to kottera.com. `TestFooter` holds it.
- **The static files.** Every file of `site/public` is served at its own
  path, byte for byte, and a file whose path a page has is refused.
  `TestStaticFiles` holds it, so `install.sh` is served at `/install.sh`
  once it is there.
- **The tests.** `site/site_test.go` keeps `TestSchemaIDPaths`, `TestBuild`,
  `TestGoImportPages` and `TestWorkflow`, reads the built pages in
  `TestPageCommands`, and adds `TestBuildReproducible`, which builds the
  site twice and compares the trees byte for byte. CI's `site` job also runs
  the build step's own tests.
