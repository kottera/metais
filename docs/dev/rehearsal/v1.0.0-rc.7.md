# Rehearsal record — metais v1.0.0-rc.7

The record of the release candidate `v1.0.0-rc.7`, a candidate of Wave 3 of
[PLAN-2026-10-metais-public](../../plans/PLAN-2026-10-metais-public.md)
(§8). It is the next candidate after `v1.0.0-rc.6`, cut once W3-13 fixed
`install.sh`'s lookup of the latest release (ruling R-W3-4): each defect
becomes a fix item, and the next candidate goes through every step. The
candidate was cut by the release procedure of
[`docs/dev/release.md`](../release.md), "The release procedure", steps 1 to
6, as ADR-013 D7 item 3.1 gives it, by W3-14. Each later act and check of
the rehearsal records its evidence in its own section below. W3-7 completed
the record from W3-OOB6's and W3-OOB7's reports, W3-OOB7's scrubbed set, and
GitHub's own record of each run, release, tag and tap commit.

**Outcome: published, and passed every check.** `release.yml` pushed the
tag, published the prerelease, updated the tap and deployed metais.org. All
eight of the rehearsal's jobs passed, and I1 passed on Opus, Sonnet and
Haiku, each with a recorded verdict. It is the latest candidate, and its
I1 set is the rehearsal's gated result
([across candidates](#the-rehearsal-across-candidates)).

### Findings

W3-OOB7 raised the first five; the sixth is W3-7's, from the scorecard.
They are recorded here and fixed by none of this wave's items so far; the
plan orchestrator files them after the wave's verification. None is a red
check of this candidate.

1. **`no-memory-read` cannot tell a repository's `CLAUDE.md` from a
   harness's memory**, so a session that discovers METAIS by cloning its
   repository is always invalid (`internal/tools/ux/checks.go`).
2. **Sessions on a person's host write outside the run**, under `/tmp`:
   I2 `opus[1m]` cloned and built there, and I1 `haiku` saved the install
   script there. `writes-inside-run` does not see a command line's writes.
   W3-OOB7 removed both after the set (`internal/tools/ux/checks.go`,
   ux-testing.md).
3. **The documented one-liner refuses until `v1.0.0` exists**, by design
   (ADR-013 D6 item 7, R-W3-4): `curl -fsSL https://metais.org/install.sh |
   sh` refuses while only prereleases exist (`site/public/install.sh`, the
   install page).
4. **ux-testing.md's re-score example names scenarios the runner
   refuses**: `-scenarios I1-install-and-render,I2-discover` answers
   `ux: no scenario I1-install-and-render`, and `I1,I2` works
   (`docs/dev/ux-testing.md`, "Scrubbing a set").
5. **The scorecard's Thresholds line says "0 runs are invalid"** while its
   table holds I2 `opus[1m]` invalid; it counts gated runs only
   (`internal/tools/ux/scorecard.go`).
6. **The scorecard's `metais` row names the runner's build**,
   `0.0.0-devel`, not the candidate the install scenarios' sessions
   installed and ran (`internal/tools/ux/scorecard.go`).
