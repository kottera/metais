# Rehearsal record — metais v1.0.0-rc.7

The record of the release candidate `v1.0.0-rc.7`, a candidate of Wave 3 of
[PLAN-2026-10-metais-public](../../plans/PLAN-2026-10-metais-public.md)
(§8). It is the next candidate after `v1.0.0-rc.6`, cut once W3-13 fixed
`install.sh`'s lookup of the latest release (ruling R-W3-4): each defect
becomes a fix item, and the next candidate goes through every step. The
candidate was cut by the release procedure of
[`docs/dev/release.md`](../release.md), "The release procedure", steps 1 to
6, as ADR-013 D7 item 3.1 gives it, by W3-14. Each later act and check of
the rehearsal records its evidence in its own section below.

## The candidate

- **Version:** `1.0.0-rc.7`, a prerelease.
- **Target commit:** `b49b10fb0139dee8fbf8d7c99367c5768a3e39ee`, `main`'s tip
  when the item started, W3-13's merge (#347).
- **Since `v1.0.0-rc.6`**, whose target is
  `6bb95fa11703945e85de8b74730d81eafa5be175` (#344), two changes merged:
  - W3-12 (#346): the UX scorer reads zsh's `command not found`, and the
    scrubber removes a host's `PATH` and local times from a set;
  - W3-13 (#347): `install.sh` finds the latest stable release by
    github.com's redirect, not by the rate-limited GitHub API.

  Neither changes the tool, nor `.github/workflows`: the candidate's tool is
  unchanged since `1.0.0-rc.3`, and its workflows are `main`'s.
- **Cut:** 2026-10-25, in a fresh clone of `kottera/metais` at that commit,
  with the toolchain `go.mod` names, `go1.26.2`, on darwin/arm64.
- **Tag in the clone:** the annotated tag `v1.0.0-rc.7` at the target commit,
  message `metais 1.0.0-rc.7`, made in the clone only. No `spec-*` tag was
  made: a prerelease releases no specification (ADR-011 A8 item 5). The
  builder said so as it started:

  ```text
  the prerelease 1.0.0-rc.7 implements 1.0, which is not released: there is no annotated tag spec-1.0
  ```

## The draft release

Created with:

```bash
gh release create v1.0.0-rc.7 --draft \
  --target b49b10fb0139dee8fbf8d7c99367c5768a3e39ee \
  --title "metais 1.0.0-rc.7" --notes-file "$TMPDIR/notes.md" \
  dist/*
```

- **URL:** <https://github.com/kottera/metais/releases/tag/untagged-5d815033dcf995d547ed>,
  the draft's own address until it is published.
- **As GitHub holds it:** tag name `v1.0.0-rc.7`, title `metais 1.0.0-rc.7`,
  a draft, target `b49b10fb0139dee8fbf8d7c99367c5768a3e39ee`, exactly the
  four archives and `SHA256SUMS`. Each asset's digest as GitHub reports it
  equals its line above, and `SHA256SUMS`'s equals the file's own. The draft
  is not yet marked a prerelease: `release.sh`'s `publish` marks it one,
  since the version has a prerelease suffix.
- **Notes:** they carry no `Specification release:` line, since a prerelease
  releases no specification (ADR-013 D7 item 3.3).
