## Why it was retired

GitHub refuses a push by a GitHub App, `GITHUB_TOKEN` among them, that
creates or updates a workflow, unless the token holds the `workflows`
permission, which `GITHUB_TOKEN` can never hold. The target `7ff24d39`
holds workflows older than `main`'s: since it, #328 (W3-8) pinned every
action to a commit SHA, and #333 (W3-9) fixed `release.yml`. So the tag's
push was read as a change to `.github/workflows/ci.yml`, and refused, as
the log above shows.

Ed ruled in W3-OOB4:

- no new credential is given to `release.yml`;
- `release.sh prepare` refuses, before anything is pushed, a draft whose
  target's workflows are not `main`'s (W3-10, #335);
- a new candidate is cut at `main`'s tip.

So the draft was deleted, never published, and `v1.0.0-rc.2` was cut at
`39184c8e` ([v1.0.0-rc.2.md](v1.0.0-rc.2.md)). No `v1.0.0-rc.1` tag or
release exists, and the number is not reused.
