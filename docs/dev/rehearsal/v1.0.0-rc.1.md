# Rehearsal record — metais v1.0.0-rc.1

The record of the release candidate `v1.0.0-rc.1`, the first candidate of
Wave 3 of [PLAN-2026-10-metais-public](../../plans/PLAN-2026-10-metais-public.md)
(§8). The candidate was cut by the release procedure of
[`docs/dev/release.md`](../release.md), "The release procedure", steps 1 to
6, as ADR-013 D7 item 3.1 gives it, by W3-6. Each later act and check of the
rehearsal records its evidence in its own section below.

## The candidate

- **Version:** `1.0.0-rc.1`, a prerelease.
- **Target commit:** `7ff24d39941cf41106ac7e294082d56cf26a9668`, `main`'s tip
  when the item started (W3-2, #324). It includes W2-NB1 (#319), W2-NB2
  (#321) and W2-NB3 (#318). W2-NB4 had not merged.
- **Cut:** 2026-10-24, in a fresh clone of `kottera/metais` at that commit,
  with the toolchain `go.mod` names, `go1.26.2`, on darwin/arm64.
- **Tag in the clone:** the annotated tag `v1.0.0-rc.1` at the target commit,
  message `metais 1.0.0-rc.1`, made in the clone only. No `spec-*` tag was
  made: a prerelease releases no specification (ADR-011 A8 item 5). The
  builder said so as it started:

  ```text
  the prerelease 1.0.0-rc.1 implements 1.0, which is not released: there is no annotated tag spec-1.0
  ```

## The builder's two runs

with `dist/` moved aside between the runs. Each run built every target twice
and matched its two copies. The two runs' `dist/` were then compared:

```text
$ diff -r "$TMPDIR/dist.1" dist && echo "the two runs are byte-identical"
the two runs are byte-identical
```

## The draft release

Created with:

```bash
gh release create v1.0.0-rc.1 --draft \
  --target 7ff24d39941cf41106ac7e294082d56cf26a9668 \
  --title "metais 1.0.0-rc.1" --notes-file "$TMPDIR/notes.md" \
  dist/*
```

- **URL:** <https://github.com/kottera/metais/releases/tag/untagged-c067cba4bf298fc5c868>,
  the draft's own address until it is published.
- **As GitHub holds it:** tag name `v1.0.0-rc.1`, title `metais 1.0.0-rc.1`,
  a draft, target `7ff24d39941cf41106ac7e294082d56cf26a9668`, exactly the
  four archives and `SHA256SUMS`. Each asset's digest as GitHub reports it
  equals its line above.
- **Notes:** they carry no `Specification release:` line, since a prerelease
  releases no specification (ADR-013 D7 item 3.3).
