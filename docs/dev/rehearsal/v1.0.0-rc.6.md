### Why `install-macos` failed

`install.sh` with no `METAIS_VERSION` asked the GitHub API anonymously for
the latest release, `GET
https://api.github.com/repos/kottera/metais/releases/latest`. On the
macOS runner GitHub answered `403`, its anonymous rate limit on the shared
runner egress, where the check expects the `404` that "no stable release"
comes from. `install.sh` reported the 403 honestly and refused, and the
check refused its refusal, since it does not name the missing stable
release. The same check passed on `install-ubuntu` and `install-container`
in the same run, and on macOS for `v1.0.0-rc.4` and `v1.0.0-rc.5`.

The candidate did not cause the 403, but a user behind a shared address
meets the same refusal, so R-W3-4 made it a defect fixed in this wave.
W3-13 (#347) finds the latest stable release by github.com's redirect,
which is not rate-limited that way, and `v1.0.0-rc.7` carries it. Its
`install-macos` passed this check unchanged.
