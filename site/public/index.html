METAIS

Multi-file Extensible Templating And Instantiation Specification.

A METAIS package is a document template in one file, usually named <name>-<version>.metais. It says which inputs a document needs, with a JSON Schema and a prose explanation for each one, and it carries the Liquid templates that render the document from them. One package can produce anything from a Markdown report to a set of files for a static site.

metais is the reference tool. It reads a package in place, without unpacking it, checks the data you supply against the package's schemas and reports every problem at once, and renders the outputs. It never runs code from a package and never touches the network, and the same package and data give the same bytes on every platform. It also helps authors write, check, test and pack their own packages.

Where to go next

  • Someone gave you a .metais file: install metais, then follow Use a package.
  • You want to write a package: install metais, then follow Write a package.
  • You are building another implementation: the specification's JSON Schemas are published at their $ids under https://metais.org/schemas/.
