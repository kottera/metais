# Appendix B. A worked package

**Informative.** No statement area.

This appendix builds one small package step by step on the authoring path of
chapter 13, from an empty directory to a packed package: a manifest, one input
with its schema and its meaning document, two templates, and one example.
Every file it shows is included from a vector of the conformance suite, so
what it shows is what a conforming authoring tool accepts. It is the page an
author new to METAIS starts from.
